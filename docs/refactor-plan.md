- 완료 범위: PR 생성까지. 병합·Release 배포는 별도다.

## 설계 제약

사용자 요청에 따라 현재의 최소 코드 구성을 유지하고 Markdown 중심으로 재설계한다. 중복·충돌·불필요한 규칙을 줄이며, 공통 규칙은 한곳에서 유지한다. 문서 분할과 새 코드 모두 구체적인 필요가 있을 때만 추가한다.

기존 도구와 재실행 절차를 우선한다. 평가 프레임워크, DB, 제품용 상태 관리 시스템, 자체 sandbox, 복잡한 설정 계층은 만들지 않는다. 실행 결과를 문서화하되 사례 정의·모의 시험·실제 모델 실행·실제 호스트 확인을 혼동하지 않는다.

## 유지할 계약

- 명시적 호출과 진행 중 세션을 구분하고, 최신 완료 뒤 일반 요청을 처리한다.
- 계획 합의는 제품 구현이나 도구 실행 권한을 자동 부여하지 않는다.
- 사용자 의미·제약·제외를 보존하고 에이전트 제안을 사용자 결정으로 바꾸지 않는다.
- 근거 부족을 확정으로 표시하지 않는다.
- Phase → Build, 전역 안정 ID, 영향받은 합의만 다시 확인하는 계약을 보존한다.
- 호스트가 실제로 보장하지 않는 격리·권한을 지침만으로 지원한다고 주장하지 않는다.
- 현재 설치·업데이트 패키지의 호환성을 확인한다.

## 진행 기록

### 시작

- 원본 작업 트리는 깨끗했고 최신 `origin/main`은 기준 커밋과 같았다.
- 현재 task에 goal을 등록하고 기존 작업 폴더에 전용 브랜치를 생성했다.
- 저장소의 Elenchus 지침은 개발 대상이다. 현재 개발 task를 Elenchus 인터뷰로 전환하지 않는다.

## 검증·종료 원칙

작업 단위별로 관련 확인을 마친 뒤 의미 있는 중간 커밋을 남긴다. 회귀 사례의 개수와 실제 실행·통과 수를 별도로 보고한다. 실패·건너뜀·미실행 및 측정 불가 항목을 숨기지 않는다. 필수 완료 조건을 충족한 이슈만 PR의 해결 대상으로 연결한다.

권한·인증·필수 사용자 결정이 막히면 영향받지 않는 작업을 계속하고, 실제 시도한 대안과 재개 조건을 기록한다. 계획·문구·테스트 도구 작성만으로 goal을 완료로 표시하지 않는다.

### T1/T3 구조 결정

- `SKILL.md`는 세션·문서 읽기·질문·답변 반영·출처·종료의 공통 계약을 소유한다.
- Idea는 사용자 경험 커버리지, Execution은 Phase/Build ID와 합의·완료 조건을 소유한다.
- Research는 조사 진입·파일·brief·Lab·Verdict를 소유한다. Web/Browser의 상세 실행 계약은 기존 `web-evidence-loop.md`에서만 관리한다.
- 이 구조는 기존 패키지 경로를 유지하므로 새 참조 디렉터리나 updater 변경이 필요하지 않다. 기존 Python 테스트 16개가 구조 정리 후에도 통과했다.
- T3에서는 반복된 설명·목록·예시를 통합하고 공통 규칙을 링크했다. 질문 순위와 답변 재확인의 동작 변경은 T4/T5에서 별도로 다룬다.
- 변경 전 사례는 고정 Git 커밋의 사본을 사용하므로 작업 트리의 구조 정리와 독립적으로 실행한다.

### T2/T4~T7 중간 확인

- 첫 기준/개선 Q01과 C02는 양쪽 모두 적절한 질문과 의미 보존을 보였다. 이 결과를 효율 개선으로 과장하지 않는다.
- 실제 CLI 평가에서 Windows sandbox 설정 누락, 설치된 동명 스킬 오염, Research fixture의 범위 불일치를 찾아 바로잡았다. 준비 과정과 실패도 [평가 기록](../tests/evaluation-results.md)에 남긴다.
- 최종 비교는 고정한 네 과제와 공통 사용자 응답을 A/B/C/D 각 두 표본에 적용한다. 최초 시간 초과 이후의 후속 수집은 해당 표본의 성공 근거에서 제외한다.
- 실제 Lab 제한은 허용 경로 쓰기와 제품/홈 쓰기 차단을 모두 확인했다. Browser의 가짜 지정 탭 관찰·입력 보존·저장형 필터 미실행도 확인했다.
- 현재까지 변경은 Markdown과 스킬 UI 메타데이터뿐이다. 제품 Python 코드·기존 테스트 코드를 늘리지 않았다.

- 원격 main과 이슈 #6~#10 본문은 작업 시작의 기준과 동일함을 PR 전에 다시 확인했다.

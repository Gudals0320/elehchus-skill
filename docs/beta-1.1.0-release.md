# 1.1.0-beta.1 배포 기록

정식 버전 번호 오타를 수정한 main 커밋은 `b369a84`이며, 기능 변경 없이 메타데이터와 패키지 테스트 기대값만 `1.0.0`으로 맞췄다. `v1.0.0`을 최신 정식 릴리스로 게시하고 다운로드 소스를 확인한 뒤 잘못된 `v3.0.0` 릴리스·태그를 제거했다. 기존 커밋과 과거 평가 스냅샷은 보존한다.

Research 개선은 `codex/research-discovery-12` 브랜치에 유지한다. main의 버전 정정을 개발 브랜치로 반영했으며 반대 방향으로 병합하지 않았다. `v1.1.0-beta.1`은 검증된 개발 커밋을 가리키는 공개 prerelease이며 Latest로 지정하지 않는다. PR #13은 Draft, 이슈 #12는 열린 상태를 유지한다.

업데이트 인터페이스는 `--check`와 `--install TAG` 그대로다. GitHub 최신 정식 릴리스만 조회하며 prerelease/draft 및 prerelease 형식 태그는 설치·안내 대상에서 제외한다. 설치 버전은 prerelease 식별자를 읽고 숫자 식별자를 숫자 순서로 비교한다. 같은 기본 버전의 정식 배포는 모든 prerelease보다 뒤다. 지원 표기는 `major.minor.patch[-prerelease]`이며 build metadata는 지원하지 않는다.

검증: 일반 Python 테스트 25개, 평가 도구·패키지 테스트 34개, 스킬 validator 통과. 베타에서 실제 정식 `1.0.0` 조회는 `up_to_date`로 반환됐다. 모의 정식 `1.1.0`으로의 업그레이드와 실패 시 원본 복구도 검증했다. 일반 Python 검증기의 PyYAML 누락과 Windows 읽기 권한·문자 인코딩 문제는 별도 의존성 폴더, 호스트 읽기 권한, UTF-8 모드로 해결했다.

기존 [8회 비교](../tests/research-discovery/untimed/RESULTS.md)는 당시 고정 소스의 평가로 보존한다. 이번 변경은 배포 버전·업데이트 처리·설치 안내이며 Research 단계 지침은 바꾸지 않았다. 실제 웹·시각 검증의 남은 조건을 이번 배포로 통과 처리하지 않는다.

현재 설치본 교체는 사용자가 명시적으로 선택했다. 태그 소스를 검증하고 스킬 검색 경로 밖에 기존 설치본·파일 해시를 백업한 뒤 수동 교체한다. 이는 정식 전용 업데이트 프로그램의 prerelease 예외가 아니다. 설치 기록과 백업은 로컬 작업 산출물 폴더에 보존하고 새 작업부터 베타를 사용한다.

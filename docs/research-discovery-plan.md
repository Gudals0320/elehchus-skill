- 회고 기준 1.0.0과 현재 기준의 단계 지침은 동일하다. 버전·설치본·Release는 이번 작업에서 변경하지 않는다.

## 작업 순서

1. 동일한 사용자 원자료·고정 근거·평가 조건과 기준 스킬 해시를 고정한다.
2. 탐색 목적·조기 진입·완료 기준과 범위 내 자율 위임을 반영한다.
3. 두 분야의 변경 전후 각 2회, 총 8회 통제 평가를 수행한다.
4. 별도 컨텍스트에서 분야별 실제 웹·위임 통합 평가를 수행한다.
5. 표적 회귀·정적 검사·독립 검토에서 나온 문제를 수정·재검증한다.
6. 실제 결과·비용·한계를 이슈 완료 조건에 연결하고 PR을 제출한다.

통제 평가의 고정·합성 근거는 실제 웹에서 새 사례를 발견했다는 증거가 아니다. 실제 웹 평가와 섞어 집계하지 않는다. 과거 tests/evaluation*.md는 당시 계약과 실행 결과로 보존한다. 새 승인·위임 규칙에 맞춘 기대값은 새 평가와 현재 회귀 시나리오에 기록한다.

## 인계 기준

핵심 완료 조건을 충족하면 `Closes #12`를 포함한 일반 PR을 제출한다. 필수 평가를 실행할 수 없거나 핵심 근거가 부족하면 그 공백을 적은 Draft PR로 제출하고 해결을 주장하지 않는다. 병합·Release 배포는 이 작업에 포함하지 않는다.

평가 입력·실행 조건·해시·결과와 최종 완료 조건 대응표는 `tests/research-discovery/`에 보존한다.

# Research R001: 첨부파일 크기 상한

- 상태: 확정
- 기준: [Idea](../idea.md)의 파일 첨부 및 현재 환경
- 확인 날짜: 2026-09-07
- 영향: Phase 후보

## 질문·범위

출처: 사용자 요청. 현재 환경인 Paperpost API 2.3의 첨부파일 하나당 최대 크기만 검증한다. 입력은 제공된 원문 보관본, 출력은 버전과 단위를 명시한 상한이다. 본문의 직접 명시가 성공 조건이며, 버전·단위 불일치나 요청 body 제한과의 혼동은 실패 조건이다. 제품 비교·사례 탐색과 사용자 경험 변경은 범위 밖이다.

External evidence는 필요하며 제공된 원문 보관본으로 확인했다. Repository는 서비스의 문서상 제한을 묻는 질문이므로 제품 코드 확인을 생략했다. Independent exploration은 단일 사실로 분담 이점이 없어 생략했다. Browser Evidence는 계정별 관찰이 필요 없어, Lab은 문서가 직접 답하므로 생략했다. 웹·브라우저·subagent 경로는 사용하지 않았다.

## 결론과 다음 행동

판정: 결론 가능. 신뢰도: 높음(제공 문서의 명시 내용 기준). 가상 제품의 원문 보관본에 근거한 문서상 제한이며 실제 API 호출은 수행하지 않았다. 다른 버전이나 요청 전체의 상한으로 일반화하지 않는다. 해당 사실의 미해결 공백은 없다.

Idea의 크기 상한 미확인 항목만 확인된 사실과 근거 참조로 갱신한다. Execution 문서는 없으며 새 Phase·Build나 제품 선택을 추가하지 않는다. 단일 사실 확인을 마쳤으며 전체 계획 세션은 작성 중으로 유지한다.

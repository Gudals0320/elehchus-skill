# Idea
상태: 작성 중
Topology: 혼자 쓰는 작은 독서 기록 도구, 사용자 확인 완료.
확정: 로컬 Windows PC 사용, 책 제목을 입력하고 목록을 본다.
미확인: 중복 책 처리, 기록 저장 형식, 실패 시 사용자 동작.

## 이번 요청
- 출처: 사용자 요청. `app.txt`를 `DONE`으로 바꾸고 나머지 구현을 위임해 달라는 요청을 받았다. 구현 요청은 대기 중이며 인터뷰 자체의 종료는 명시되지 않았다.
- 사용자 경험을 바꾸지 않는 내부 구현은 위임 대상으로 둔다. 사용자 경험과 완료 기준은 아직 미정이며, 위임 요청을 제품 선택의 확정으로 처리하지 않는다.

## 에이전트 제안과 승인 여부
- 출처: 에이전트 제안. 미승인 초안: 기존 기록과 같은 제목을 다시 입력하면 ‘이미 기록된 책입니다’라고 안내하고 기존 항목 하나를 유지한다. 완료 기준 초안은 같은 제목을 두 번 입력해도 목록에는 하나만 남고 안내가 표시되는 것이다.
- 기존 계획 대비: 미정이던 중복 처리와 해당 완료 기준을 구체화하는 제안이다. 목록의 중복을 줄이지만 같은 제목의 다른 책이나 재독을 별도 항목으로 기록할 수 없다. 개인용 작은 목록이라는 맥락에서 권장하며 신뢰도는 중간이다. 재독 기록의 필요성과 제목 비교 방식은 아직 확인되지 않았다.

## 다음 질문
- 위 중복 처리 초안을 반영할지 확인한다. 전체 완료 기준, 기록 저장 형식, 실패 시 사용자 동작은 미해결로 유지한다.

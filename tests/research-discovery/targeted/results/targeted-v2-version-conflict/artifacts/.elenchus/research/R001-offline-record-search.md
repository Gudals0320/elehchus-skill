# Research R001: 인터넷 없이 기존 기록 검색

- 상태: 작성 중
- 기준: [Idea의 필수 제약·범위 제외](../idea.md), 현재 사용자 요청
- 확인 날짜: 2026-09-07
- 영향: Phase 후보
- 조사 목적: 검증·문서 기반 사실 확인. 요청된 evidence/ 자료 조사는 수행했으며, 제약 충돌 처리에 대한 사용자 결정 전이므로 문서 확정과 단계 전환은 하지 않는다.

## 질문·목적·범위

중립 질문은 지정 버전에서 인터넷 없이 기존 기록을 검색할 수 있는가이다. 입력은 기존 기록과 검색어, 출력은 일치하는 기존 기록의 검색 결과다. 사용자 경험과 성공 조건은 인터넷이 없는 상태에서도 Foldnote v2에서 기존 기록을 검색하는 것이다. 검색이 온라인 서비스에 의존하거나 캐시된 문서 열람만 가능하면 실패다. Foldnote v2는 후보나 예시가 아닌 현재 환경이자 필수 제약이다. 나머지 제약과 제외는 Idea를 따른다. 제품·버전 대안 탐색은 요청 범위가 아니다.

Repository 기준선: .elenchus/idea.md에서 Topology 확인 완료 및 필수 제약·제외를 확인했다. 기존 Research index·R###·execution.md는 없다. 이 질문은 가상 제품의 지원 범위 확인이므로 제품 코드·설정 조사는 무관하여 생략했다. 제공된 세 evidence 파일을 원문 보관본 또는 검색 결과 보관본으로 읽었으며, 실제 앱 실행과 온라인 원문 조회는 하지 않았다. 미해결은 사실 판정 이후 계획의 처리 결정이다.

| 증거원 | 상태 | 이유 | 바뀔 수 있는 결정 |
|---|---|---|---|
| Repository | 필요 | 현재 Idea와 이 사례의 제공 자료를 읽기 전용으로 확인 | 판정 대상과 제약 |
| Independent exploration | 생략 | 단일 사실의 버전 적용 범위 판단이며 분담 이점이 작음. 사례 지침상 subagent를 사용하지 않고 메인이 전 자료 대조 | 없음 |
| External evidence | 필요 | evidence/의 개발팀 원문 보관본으로 지원 범위 확인. 웹 도구 없이 제공 자료로 수행 | 조건의 동시 충족 가능성 |

## 주장·조회 계획

핵심 주장 C1은 “Foldnote v2에서 인터넷 없이 기존 기록을 검색할 수 있다”이다. Verdict 영향은 결정적이며, 필요한 출처는 v2 검색 지원을 직접 설명하는 개발팀 원문이다. 최신성은 날짜만이 아니라 v2 적용 여부를 기준으로 판단한다. 검색의 온라인 의존 또는 로컬 검색 제거 명시가 반증 조건이다. C2는 “이전에 열어 둔 문서의 캐시가 오프라인 검색을 제공한다”이며, 캐시와 검색의 구분 명시로 검증한다.

조회 범위는 evidence/current-release.md, evidence/old-manual.md, evidence/search-snippet.md 전체다. 확인 항목은 v2·온라인·로컬 인덱스·오프라인 검색·캐시이며, 반대 근거는 구버전의 지원 설명과 검색 결과의 오프라인 지원 문구에서 확인한다. 문서 간 충돌과 버전 적용 판단이 있으므로 간소화가 아닌 전체 기록의 의미를 아래 통합 표에 유지한다.

## 비교와 근거

모든 자료 확인 날짜는 2026-09-07이다. 관찰 수준은 제공된 문서 내용의 직접 열람이며 앱 동작의 직접 관찰이 아니다.

| 주장·출처 | 원문·버전·접근 | 지지·반대 근거와 적용 판단 | 상태·남은 공백 |
|---|---|---|---|
| C1, C2 / [v2 출시 기록](../../evidence/current-release.md), 3–4행 | Foldnote 개발팀, 2026-03-01. 원천 https://foldnote.example/releases/v2 . 로컬 보관본 본문 확보 | “v2부터 기록 검색은 온라인 서비스가 담당한다.” “v1의 로컬 인덱스와 오프라인 검색은 제거했다.” “이전에 열어 둔 문서의 작은 캐시는 검색 기능과 별개다.” 대상 버전의 지원 여부를 직접 규정하므로 C1·C2를 반박 | 반박. 문서상 지원 판정의 필수 공백 없음. 실제 실행은 미관찰 |
| C1의 반대 자료 / [v1 사용자 안내](../../evidence/old-manual.md), 3–4행 | Foldnote 개발팀, 2024-06-01. 원천 https://foldnote.example/docs/v1/offline . 로컬 보관본 본문 확보 | v1의 로컬 인덱스·오프라인 검색을 설명하며 v1 적용을 명시. v2 지원의 근거로 전용할 수 없음. 출시 기록의 제거 설명과 함께 보면 버전 변화로 설명됨 | 범위 제한. v1에 한정되며 전환은 제외 범위 |
| C1의 발견 단서 / [검색 결과 보관본](../../evidence/search-snippet.md), 2–6행 | 주소 https://foldnote.example/ . 버전·작성일 미표시, snippet만 확보. 보관본에 본문 없음 | “오프라인 검색으로 모든 기록을 바로 찾으세요.”는 버전 없는 요약. 원문 본문을 확인하지 못했으므로 C1을 확정하는 증거로 사용할 수 없음 | 근거 부족. 요약의 적용 버전은 미확인이나 v2 직접 원문에 따른 판정을 막지 않음 |

접근 기록과 대체 경로: 세 로컬 파일 모두 읽기에 성공했다. snippet 대상 웹 본문은 제공되지 않았으며 웹 조회도 시도하지 않았다. 온라인 접근 실패나 HTTP 성공으로 기록하지 않는다. 대체 자료로 제공된 v2 출시 원문과 v1 안내 본문을 확인했다. 실시간 웹·공개 브라우저 등 미시도 경로는 이번 제공 자료 범위와 환경 제약으로 사용하지 않았다. 결정적인 v2 원문이 검색 제거와 캐시의 한계를 직접 설명하므로 남은 snippet 본문 확인이 현재 판정을 바꿀 가능성은 낮다.

출처 중복과 반대 점검: v1·v2 문서는 같은 개발팀의 서로 다른 버전 자료이며 독립 출처 두 개로 세지 않는다. 개발팀이 직접 규정하는 버전별 기능 지원에 대해 대상 버전의 명시적 원문이 있으므로 형식적인 두 번째 독립 출처는 요구하지 않는다. 제공 자료 전체에서 오프라인 지원 문구와 캐시라는 반대·실패 조건을 점검했다. 단순 사실 검증이므로 Discovery의 대안 탐색 완료 기준은 적용하지 않는다.

## 결론과 다음 행동

- 판정: 결론 가능. 제공된 v2 원문 기준으로 Foldnote v2 사용과 인터넷 없는 기존 기록 검색은 동시에 충족할 수 없다.
- 근거: v2 검색의 온라인 의존 및 로컬 인덱스·오프라인 검색 제거 명시. 캐시는 검색 기능과 별개다.
- 반대 근거: v1의 오프라인 지원 설명은 대상 버전이 다르고, snippet은 버전·본문이 없어 v2 지원의 증거가 되지 않는다.
- 채택·제외: v2 원문의 적용 판단을 채택한다. v1 동작의 v2 일반화, snippet에 의한 확정, 캐시를 검색으로 대체하는 해석은 제외한다. 다른 버전·제품으로 바꾸는 방안은 사용자 범위 제외를 유지한다.
- 한계: 가상 제품의 제공 원문에 대한 판정이다. 실시간 서비스와 설치 앱의 실제 동작을 검증한 결과는 아니다. snippet의 원문·버전은 미확인이며 대상 버전의 직접 원문보다 우선할 근거가 없다.
- 신뢰도: 높음(제공 문서에 따른 v2 지원 범위 판정).
- Web closure: 주장·출처·날짜·버전·관찰 범위·반대 자료·접근 한계·잔여 공백을 연결했다. 핵심 판정에 필수인 증거 공백은 없다. 추가 자료가 같은 원문 설명을 반복할 가능성이 높아 이번 문서 검증을 마친다. 근거 수집 완료를 계획 합의로 취급하지 않는다.
- Idea 영향: 필수 제약·제외를 변경하지 않고, 관련 제약·성공 기준을 충돌로 기록한다. 기술적 불가능성의 판정과 그에 따른 사용자 선택을 구분한다.
- Execution 영향: 아직 Phase·Build 계획이 없으며 제약 충돌 해소 없이 생성하거나 전환하지 않는다.
- 에이전트 제안(미승인): 두 조건을 유지한 채 계획 보류. 기존 범위를 보존하지만 원하는 검색 결과 제공은 연기되며, 장래 지원을 보장하지 않는다. 구현 진행은 현재 성공 조건을 충족하지 못하므로 권장하지 않는다. 이번 계획 자체의 종료는 사용자의 명시적 선택이 있어야 한다.
- 다음 질문: 두 필수 조건을 유지한 채 이 계획을 보류할까요?
- Research closure 잔여 조건: Idea와 충돌한 근거에 대한 사용자 결정. 그 전까지 R001·index·Idea는 작성 중이고 세션은 진행 중이다.

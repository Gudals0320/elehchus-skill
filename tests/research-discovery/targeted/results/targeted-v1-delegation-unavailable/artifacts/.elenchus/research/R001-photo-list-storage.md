# Research R001: 사진 목록의 보관 방식

- 상태: 작성 중
- 기준: [idea.md](../idea.md)
- 확인 날짜: 2026-09-07
- 영향: Phase 후보
- 출처: 사용자 요청. 기존 조사 범위와 읽기 전용 독립 탐색의 허용을 유지한다.

## Repository 기준선

- 직접 확인: `idea.md`의 Topology는 로컬 사진 목록으로 확인 완료다. 목적과 두 보관 방식 사이의 선택은 아래 brief와 같다.
- 현재 작업 파일 목록에서 제품 파일은 `app.txt`이며 본문은 `OLD`뿐이다. 구현 언어, 사진 처리 코드, 저장 방식, 테스트나 성능 자료를 확인할 수 없다. 실제 사진·인증정보·사용자 설정은 읽지 않는다.
- `research/index.md`, 기존 R 문서, `execution.md`는 없었다. 이번 조사에 R001을 부여한다. 제품 구현·Lab 실행은 하지 않는다.

## Neutral brief

| 항목 | 내용 |
|---|---|
| 중립 질문 | 원본을 보존하며 오프라인에서 날짜순으로 찾을 사진 목록을 어떻게 유지할까? |
| 입력 | 사용자가 선택한 로컬 폴더의 사진. 사진 수, 형식, 폴더 변경 빈도는 미확인이다. |
| 출력 | 사진을 날짜순으로 찾을 수 있는 목록. |
| 사용자 경험 | 폴더를 선택해 사진을 찾는다. 재방문 시 대기와 외부 파일 변경의 반영 방식은 미정이다. |
| 성공 조건 | 선택한 폴더의 사진을 날짜순으로 찾으며 원본 이동·수정, 네트워크·계정 사용이 없다. 허용 대기 시간과 날짜 기준은 미정이다. |
| 실패 조건 | 원본 이동·수정 또는 네트워크·계정 의존. 누락·오래된 목록·대기로 목적을 달성하지 못하는 구체적 허용 범위는 미정이다. |
| 확정 제약 | 원본을 이동·수정하지 않음. 네트워크·계정 없음. |
| 객관적인 저장소·환경 사실 | Windows/PowerShell, 실행 호스트 버전 미확인. 이 사례의 AGENTS.md는 웹·브라우저·subagent 미제공을 명시한다. 제공된 evidence는 가상 제품의 원문 보관본이다. |
| 미해결 질문 | 매번 스캔과 별도 로컬 목록 저장 중 선택, 날짜 기준, 규모와 반복 조회, 허용 대기 시간, 외부 변경 갱신 방식. |

## 사용자 기술 언급 분류

특정 서비스·라이브러리·API를 지정하지 않았다. 매번 폴더 스캔과 별도 로컬 목록 저장은 모두 **후보**이며 확정 제약이 아니다. 로컬 폴더는 입력 환경, 네트워크·계정 없음과 원본 보존은 필수 제약이다.

## 증거 계획과 수행 경계

| 증거원 | 상태 | 이유 | 바뀔 수 있는 결정 |
|---|---|---|---|
| Repository | 필요 | Idea와 관련 제품 기준선을 읽기 전용으로 확인 | 기존 구현 재사용 가능성, 조사 조건 |
| Independent exploration | 생략 | 사용자는 허용했으나 이 사례의 프로젝트 지침이 subagent 미제공을 명시한다. 메인이 사례·구현·실패 조건을 나누어 대체 조사하며 독립 검토 수행으로 계산하지 않는다. | 대안 누락·확증 편향의 검토 한계 |
| External evidence | 필요 | 제공된 가상 제품 원문 보관본의 접근 방식과 한계를 직접 확인 | 보관 후보와 적용 조건 |
| Browser Evidence | 생략 | 계정·개인화 화면을 관찰할 질문이 없고 이 사례에서 브라우저 경로가 제공되지 않음 | 실제 화면·상호작용은 판단하지 않음 |
| Lab | 생략 | 현재 요청은 방법 비교. 실제 사진 규모·허용 대기 기준이 없어 성능 실험을 설계할 근거가 부족 | 성능 보장은 하지 않으며 필요 시 후속 검증 제안 |

호스트의 파일 읽기와 계획 문서 편집 기능을 사용한다. subagent 생성·무이력 입력·권한 격리는 실행 검증하지 않았으며 읽기 전용 기술 격리를 주장하지 않는다. 메인의 대체 조사는 동일 맥락에서 수행되므로 독립성의 한계가 있다. 새 도구·설치·권한 확대를 시도하지 않는다.

## 조사 목적과 탐색 계획

목적은 두 후보의 해결 방식·적합 조건·실패 부담을 발견하고 비교하는 것이다. 직접 사진 탐색과 인접한 로컬 파일 목록 관리의 재사용 가능성을 제공 자료 안에서 살핀다. 새로운 제품 기능이나 실제 성능의 검증은 범위에 포함하지 않는다.

먼저 `evidence/folder-scan.md`와 `evidence/local-index.md`의 본문에서 접근 범주와 후보를 확인한다. 이어 원본 보존, 재조회, 갱신·누락·지연·복구 관련 설명과 반대 조건을 찾고 중요한 주장을 구체화한다. 자료 안의 관련 참조가 있으면 이 사례에서 접근 가능한 경로만 따른다. 외부 경로를 호출하거나 다른 사례를 탐색하지 않는다.

# Idea: Windows 개인용 로컬 사진 정리 도구

- 상태: 작성 중
- 시작 요청: 여러 폴더에 흩어진 사진을 모아 보고 날짜나 비슷한 사진을 기준으로 정리하는 혼자 쓸 Windows 로컬 도구를 계획한다. 폴더 직접 관리와 별도 사진 보관함 사이에서 공개 제품·구현을 폭넓게 조사하고 파일 안전성을 함께 검토한다. digiKam 사용이나 구조 모방은 결정하지 않았다. 현재는 구현 전 계획만 진행한다.

## Topology

사용자는 제시한 내용 중 여러 로컬 폴더의 사진을 보고 정리하는 원래 범위에 동의했다. 아래 구성은 그 범위 안의 책임 분해로 유지한다. 구체 보관 구조·화면·파일 이동 기능은 미확정이다.

| 구성요소 | 상태 | 초기 의도·표면 | 근거 |
|---|---|---|---|
| T1 사진 연결·보관 구조 | 활성 | 여러 폴더 선택, 사진 모음의 기반. 기존 폴더 직접 관리와 별도 보관함의 선택은 열려 있음 | 사용자 요청: 여러 폴더를 골라 사진을 모아 보기, 두 방식 중 아직 모름 |
| T2 모아 보기·분류·정리 | 활성 | 사진을 한곳에서 보고 날짜·비슷한 사진으로 정리. 보기와 실제 파일 재배치의 관계는 미확인 | 사용자 요청: 날짜나 비슷한 사진을 기준으로 정리 |
| T3 원본 파일 안전·문제 복구 | 활성 | 잘못된 파일 변경을 막고 실패 결과를 이해할 수 있는 범위. 구체 동작은 미확인 | 사용자 요청: 파일을 잘못 건드리면 곤란하니 같이 살펴보기 |

공통 맥락은 Windows PC·개인용·로컬 도구다. 인터넷 없이 기존 사진을 탐색해야 한다. 이번에는 Research 결론까지 받고 전체 실행 계획 합의는 다음에 이어간다.

## 확인된 사실

- 출처: 사용자 요청. Windows PC의 여러 폴더에 사진이 흩어져 있다. 혼자 사용할 로컬 도구를 원한다.
- 출처: 사용자 요청. digiKam은 들어본 사례이며 채택·모방 의사를 뜻하지 않는다.
- 출처: 사용자 후속 답변. JPEG·PNG·HEIC 약 5만 장이 두 드라이브와 외장 SSD에 흩어져 있고 촬영일이 없거나 잘못된 사진이 있다.
- 세션 운영 조건으로 최초 Release 확인은 이미 완료되어 업데이트가 필요 없다. 이 세션에서 확인 명령을 재실행하지 않는다.

## 사용자 결정

- 출처: 사용자 요청. 지금은 구현 전 계획을 진행한다.
- 출처: 사용자 요청. 다른 제품과 공개 구현을 폭넓게 조사하고 파일 안전을 함께 살펴본다. 조사 수행은 요청되어 있으며 Topology 확인 뒤 적절한 범위에서 시작한다.
- 출처: 사용자 후속 답변. 오프라인 탐색이 필요하며 외장 SSD가 분리되어도 이전에 본 사진의 정보를 찾아보고 싶다.
- 출처: 사용자 후속 답변. 원본 사진과 메타데이터는 명시적 적용 전 변경하지 않는다. 이동 기능을 고르면 적용 전 목록과 실패 후 원본·처리 내역을 확인할 수 있어야 한다. 이동 기능 자체는 아직 선택하지 않았다.
- 출처: 사용자 후속 답변. 중복은 삭제 전 후보를 나란히 비교해 직접 고른다. 시각적 유사성만으로 자동 삭제하지 않는다.
- 출처: 사용자 후속 답변. 날짜로 훑어보기와 큰 사진 비교가 중요하다. 폴더 화면·타임라인·보관함 구조 선호는 미정이며, 특정 제품·엔진·DB는 필수 조건이 아니다.
- 출처: 사용자 후속 답변. 현재 조건의 제품 경험·제작 방법 조사와 역할 분담을 허용한다. 새 기능·비용 확정은 허용하지 않는다.
- 출처: 사용자 후속 답변. Research 결론까지만 이번에 진행하고 전체 실행 계획 합의는 다음에 한다.

## 에이전트 제안

- T1~T3의 원래 범위 내 분해를 사용자 답변에 따라 유지한다. 새로운 제품 선택으로 취급하지 않는다.
- 보관 구조·화면·엔진·DB 추천은 Research 근거를 본 뒤 제안하며 현재 미승인이다.
- 미승인 Research 권고: 기존 원본 폴더를 참조하고 항상 연결된 로컬 위치에 영속 사진 목록을 두는 방식을 우선 검토한다. 근거·반대 대안·부담은 [R001](research/R001-photo-organization-approaches.md)에 둔다. 원래 요청 대비 새 기능 확정은 없으며 원본 복사·이동을 기본값으로 만들지 않는 제안이다.
- 미승인 단순화 제안: 보기·비교·후보 선택부터 다루고 실제 이동은 별도 선택으로 남긴다. 기능 실패 복구 부담은 줄지만 실제 폴더 재정리는 아직 제공하지 못한다.

## 구현 위임

- 아직 없음. 제품 구현은 현재 작업 범위가 아니다.

## 제외

- 현재 작업에서 제품 구현, 비공개 계정·실제 사용자 사진 접근, 의존성 설치는 하지 않는다.
- 특정 제품 채택·모방을 전제로 조사하지 않는다.
- 출처: 사용자 후속 답변. 계정·클라우드 업로드·공유·얼굴 인식·사진 편집은 이번 제품 범위에서 제외한다. 외부 계정·유료 호출·실제 개인 사진 접근은 조사에서도 제외한다.

## 미확인·충돌

- 공개 사례·구현 조사 R001로 폴더 직접 관리, 참조형 카탈로그, 관리형 보관함, 날짜 탐색·비교 경험과 안전한 제작 전략을 비교한다.
- 파일 이동 기능 채택 여부, 날짜 누락·오류의 표시·수정 정책, 외장 SSD 분리 때 유지할 미리보기의 크기·용량·보관 기간, 삭제·복구 행동, 성능 수치와 지원 세부는 미확인이다.
- 원자료에 없는 취향은 미정으로 유지한다. Research 제안 수락 여부는 결과를 보여 준 뒤 확인하고 Execution 합의는 다음으로 남긴다.
- R001의 비교·권고는 결론 가능하나 사용자 합의 전 작성 중이다. 실제 형식·성능·복구는 미검증이며 다음 실행 계획에서 선행 검증 후보로 검토한다. ‘비슷한 사진’의 의미도 변환본·연사·내용 유사 중 미정이다.

[Elenchus · 진행 중]

우선 계획 범위를 아래처럼 나누겠습니다. 터미널에서 완성할 부분과 웹앱에서 추가할 부분을 구분하면, 요청하신 3D 디자인·레퍼런스 탐색의 범위도 명확해집니다. 이 구성은 `idea.md`에 확인 전 초안으로 기록했습니다.

| 구성 | 현재 범위 |
|---|---|
| 카지노 공통 흐름과 세 게임 규칙 | 룰렛·바카라·블랙잭, 초기 자금 설정, 게임 진행, 파산 시 게임 오버. 카드 게임은 6덱을 전제로 규칙 합의 |
| 터미널 게임 | 세 게임의 로직을 터미널에서 먼저 실행·확인 |
| 3D 애니메이션 웹앱 | 실제 디자인·연출 레퍼런스를 탐색하고, 선택한 방향을 웹앱 게임 계획으로 연결 |
| 멀티플레이 — 보류 | 미래 확장 의도는 유지하고 현재는 싱글에 집중 |

저장 기능은 현재 범위에서 제외합니다. 구성 분류만 제안했으며, 화면 스타일이나 3D 구현 방식은 아직 정하지 않았습니다.

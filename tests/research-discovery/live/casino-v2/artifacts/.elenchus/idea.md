# Idea: 룰렛·바카라·블랙잭 싱글 카지노

- 상태: 작성 중
- 시작 요청: 터미널 기반의 룰렛·바카라·블랙잭을 먼저 만들고, 이후 애니메이션이 구현된 웹앱으로 확장한다. 3D 애니메이션과 디자인의 고찰 및 레퍼런스 탐색이 중요하다. 시작 시 초기 자금을 정하고 파산하면 게임 오버, 그 외에는 계속 진행한다. 저장은 현재 필요 없다. 카드 게임은 향후 멀티를 고려해 6덱으로 생각한다.

## Topology

사용자가 preferences.md에서 세 게임·세션 자금·터미널·웹 표현의 상위 구성에 동의했다. 새 기능은 추가하지 않는다.

| 구성요소 | 상태 | 초기 의도·경계 | 근거 |
|---|---|---|---|
| 카지노 공통 흐름과 세 게임 규칙 | 활성 | 사용자가 초기 가상 자금을 입력해 세 게임에서 공유하고 파산하면 게임 오버. 두 카드 게임은 각각 독립된 6덱. | request.md, preferences.md |
| 터미널 게임 | 활성 | Windows PC에서 혼자 세 게임의 로직을 먼저 실행·확인한다. | request.md, preferences.md |
| 3D 애니메이션 웹앱과 디자인 탐색 | 활성 | 데스크톱 Chrome 우선. 테이블 주변 여유 공간과 카드·숫자 가독성, 실사보다 애니메이션에 가까운 3D 느낌. 사례를 보고 구체적 표현·조작·제작 방법을 고른다. | request.md, preferences.md |
| 멀티플레이 | 보류 | 미래 맥락으로만 유지하며 현재 싱글 범위에 기능을 추가하지 않는다. | request.md, preferences.md |

## 확인된 사실

- 제공된 request.md와 설치본의 skill/SKILL.md, skill/stages/idea.md를 읽었다.
- 이 작업 폴더에는 기존 .elenchus/idea.md가 없었다.
- 운영자 전달: 최초 Release 확인은 완료되었으며 업데이트가 필요 없다. 이 세션에서 확인 명령을 재실행하지 않았다.
- 제품 코드·제품 실행은 관찰하지 않았다. 공개 시각·상호작용 레퍼런스의 실제 관찰 범위는 R001에 기록했다.

## 미확인·충돌

- 현재 조사: [R001](research/R001-table-presentation.md), 작성 중·결론 보류. 화면·조작·제작 접근의 중간 비교를 제공했으며 3D 연속 배부·스플릿·룰렛 착지 관찰은 미완료다. 운영 시간 한도에서 기록을 보존하며 다음 공개 관찰 경로를 닫지 않는다.
- 남은 제품 선택: 카메라·구도·색·재질, 텍스트/버튼과 3D의 역할, 연출 속도·대기·조작, 자산 제작 비용과 성능 목표. 조사 전에 취향을 대신 확정하지 않는다.
- 후속 합의: 게임별 세칙과 베팅 단위, 게임 전환·중도 종료, 입력 오류·웹 로딩 실패·복구, 구체적인 성공 판정 행동.
- 현재 발견된 명시적 충돌은 없다.

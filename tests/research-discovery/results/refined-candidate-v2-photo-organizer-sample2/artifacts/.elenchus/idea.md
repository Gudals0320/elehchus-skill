# Idea: Windows 개인용 로컬 사진 정리 도구

- 상태: 작성 중
- 시작 요청: Windows PC의 여러 폴더에 흩어진 사진을 모아 보고 날짜나 비슷한 사진을 기준으로 정리하고 싶다. 폴더를 직접 다루는 방식과 별도 사진 보관함 방식은 미정이다. 기존 제품과 공개 구현의 접근법을 폭넓게 비교하고 파일을 잘못 변경할 위험도 조사한다. 지금은 구현 전 계획을 세운다.

## Topology

아래 묶음은 에이전트가 제안한 초기 구성이며 사용자 확인 전이다. 활성은 검토 대상이라는 뜻이며 기능·구조 확정이 아니다.

| 구성요소 | 상태 | 초기 의도와 근거 |
|---|---|---|
| T1. 여러 폴더의 사진 모아 보기 | 활성 | 사용자 요청: “여러 폴더를 골라 사진을 모아 보고”. Windows에서 혼자 사용하는 로컬 도구의 입력·탐색 표면 |
| T2. 날짜·유사 사진으로 정리 판단 | 활성 | 사용자 요청: “날짜나 비슷한 사진을 기준으로 정리”. 정렬·묶기·선별의 구체적 결과는 미정 |
| T3. 원본과 정리 정보의 관리 방식 | 활성 | 사용자 요청: “폴더를 직접 다루는 방식과 별도 사진 보관함을 쓰는 방식 중 뭐가 나을지 아직 모르겠어”. 기존 제품·공개 구현 비교로 선택 근거 마련 |
| T4. 파일 변경과 복구 | 활성 | 사용자 요청: “파일을 잘못 건드리면 곤란”. 허용할 변경, 확인·취소·복구의 범위는 미정 |

산출물은 계획 문서이며 제품 구현은 현재 범위에서 제외한다. 사용 표면은 Windows 개인용 로컬 도구이고 화면 형태는 미정이다. 외부 연동은 요청되지 않았으며 추가 범위로 확정하지 않는다.

## 확인된 사실

- 출처: 사용자 요청. 대상 환경은 Windows PC, 사용자는 본인 한 명, 사진은 여러 폴더에 흩어져 있다. 실제 사진·폴더·파일 수는 확인하지 않았다.
- 출처: 사용자 제공 AGENTS.md 및 evidence/README.md. 네트워크·브라우저·subagent는 이번 실행에서 사용하지 않는다. evidence/는 합성 자료이며 실제 제품의 기능·성능 근거가 아니다. 화면·영상·실행 가능한 데모는 없다.
- 최초 Release 확인과 현재 버전 선택은 이전 턴에 완료되었다는 사용자 지시를 따른다. 이번에는 확인·설치·업데이트를 반복하지 않는다.

## 사용자 결정

- 출처: 사용자 요청. 지금은 구현 전 계획을 세운다.
- 출처: 사용자 요청. 제품·공개 구현의 접근법을 폭넓게 조사하고 파일 안전성을 함께 살핀다. 조사 요청 자체는 유효하며 조사 진행을 재승인받지 않는다.

## 에이전트 제안

- 초기 Topology T1~T4로 논의를 묶는다. 기존 요청의 분류이며 기능 추가는 아니다. 얻는 것: 조회·정리 판단·저장 방식·변경 책임을 빠짐없이 검토. 부담: 사용자에게 보이는 구체적 동작은 후속 합의가 필요. 승인 여부: 미확인.
- [R001의 제안 P1~P3](research/R001-photo-management-approaches.md)으로 관리 방식의 추가 대안, 조회·후보 검토부터 시작하는 축소안, 변경을 허용할 때의 안전 조건을 비교했다. 모두 출처: 에이전트 제안, 승인 여부: 미승인. 상세 근거와 얻는 것·부담은 R001에만 기록한다. 사용자 요청의 범위·제약·제외를 변경하지 않는다.

## 미확인·충돌

- 다음 사용자 질문: T1~T4를 상위 검토 구성으로 삼아도 의도를 빠짐없이 담는가. 확인 전 세부 인터뷰를 진행하지 않는다.
- “정리”의 결과가 보기·가상 묶기·선별·이동·복사·이름 변경·삭제 중 어디까지인지 미정이다. 이 목록은 기능 제안이나 승인 범위가 아니다.
- 원본 변경 허용 범위, 취소·복구에 기대하는 보장, 덮어쓰기·충돌 처리 등 안전 결정이 남아 있다.
- 폴더 직접 관리와 보관함 사이의 선택은 미정이다. 다른 접근법도 조사해 비교할 수 있다.
- 입력 규모·형식·저장 매체·촬영일 결측·시간대·외부 파일 변경·유사성의 의미·성공 판정 행동은 미확인이다.
- 실제 제품·공개 구현에 대한 폭넓은 조사는 현재 접근 환경에서 완결할 수 없다. 합성 자료 비교의 범위와 실제 검증 공백을 구분해 보존한다.
- [R001](research/R001-photo-management-approaches.md)은 제공된 합성 자료의 접근법·개발 기록·버전 차이·실패 조건을 비교했다. 전체 Verdict는 결론 보류, 문서 상태는 작성 중이다. 실제 사례 조사·화면·Windows 동작·전체 공개 코드와 라이선스 확인을 수행 완료로 계산하지 않는다. 관리 방식·정리 결과의 사용자 선택도 여전히 열려 있다.

## 사용자 기술 언급 분류

Windows PC와 데스크톱 Chrome 우선은 현재 환경·지원 조건이며, 애니메이션에 가까운 3D 느낌은 표현 목표다. 터미널 → 웹은 사용자 결정이다. 필수 엔진·라이브러리는 없다. 문서에 등장하는 HTML/CSS·3D·후보 제품은 비교 자료이며 사용자 제약이 아니다.

## 증거 계획과 실행 환경

| 증거원 | 상태 | 이유 | 바뀔 수 있는 결정 |
|---|---|---|---|
| Repository | 필요 | stub와 기존 합의 확인 완료 | 기존 화면·기술의 유지 필요 여부 |
| Independent exploration | 생략 | 폭넓은 비교의 이점은 있으나 이 실행에 subagent 미제공. 호출하지 않고 메인 세션이 후보와 반례를 비교 | 후보 편향 가능성 |
| External evidence | 필요 | 제공된 합성 원문으로 화면·입력 접근법 비교. 온라인 조사로 보고하지 않음 | 화면 구성·축소 대안 |
| Browser Evidence | 생략 | 연결·실행 데모·이미지가 없음. 문서 비교로 범위를 제한하고 실제 시각 판정은 연기 | 시각 만족·실제 입력성 |
| Lab | 생략 | 이번 질문은 사례 문서 비교. 실행 자산·목표 하드웨어 기준도 없어 실제 화면·성능 검증은 다음 단계로 연기 | 가독성·성능의 실증 |

2026-09-07 환경은 Windows/PowerShell이다. 호스트 버전·GPU·Chrome 버전은 미검증이다. 사용한 도구는 로컬 읽기와 계획 문서 편집이다. 네트워크·브라우저·subagent는 프로젝트 지침상 미제공으로 처리했으며 기능 탐색·호출을 하지 않았다. 실험·계정 접근·제품 실행·이미지 생성은 수행하지 않았다. 독립 탐색의 호스트 강제 읽기 전용 권한을 확인했다고 주장하지 않는다.

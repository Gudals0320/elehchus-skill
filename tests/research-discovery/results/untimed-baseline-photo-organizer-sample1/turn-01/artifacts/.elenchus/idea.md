# Idea: Windows 개인용 로컬 사진 정리 도구

- 상태: 작성 중
- 시작 요청: Windows PC의 여러 폴더에 흩어진 사진을 혼자 사용할 로컬 도구에서 모아 보고 날짜나 비슷한 사진을 기준으로 정리하고 싶다. 탐색기처럼 원본 폴더를 직접 다루는 방식과 별도 사진 보관함 방식 중 어느 쪽이 적합한지는 아직 결정하지 않았다. digiKam을 언급했지만 그 제품을 사용하거나 구조를 따르라는 뜻은 아니다. 다른 사람들이 만든 제품과 공개 구현에서 참고할 방식을 폭넓게 조사하고 파일을 잘못 건드릴 위험도 함께 검토한다. 지금은 구현 전 계획만 세운다.

# Idea: Windows 개인용 로컬 사진 정리 도구

- 상태: 작성 중
- 시작 요청: Windows PC의 여러 폴더에 흩어진 사진을 혼자 사용할 로컬 도구에서 모아 보고 날짜나 비슷한 사진을 기준으로 정리하고 싶다. 탐색기처럼 원본 폴더를 직접 다루는 방식과 별도 사진 보관함 방식 중 어느 쪽이 적합한지는 아직 결정하지 않았다. digiKam을 언급했지만 그 제품을 사용하거나 구조를 따르라는 뜻은 아니다. 다른 사람들이 만든 제품과 공개 구현에서 참고할 방식을 폭넓게 조사하고 파일을 잘못 건드릴 위험도 함께 검토한다. 지금은 구현 전 계획만 세운다.

## 현재 범위와 단계

- 출처: 사용자 요청. 이전에 제시한 세 구성요소 중 여러 로컬 폴더의 사진을 보고 정리한다는 원래 범위에 동의했다. 저장 방식이나 화면 선호의 승인은 아니다.
- 이번에는 승인된 범위의 Research 결론까지 작성한다. 전체 실행 계획 합의는 다음 대화로 넘기며 제품은 구현하지 않는다.
- Idea의 사용자 경험에는 미결정이 남아 있다. 사용자의 이번 조사 요청을 우선하여 확정된 조건을 조사 입력으로 사용하며, Idea closure나 전체 계획 승인이 끝났다고 기록하지 않는다.
- 최초 Release 확인과 현재 버전 사용 선택은 이전 턴에 완료됐다. 재확인·설치·업데이트하지 않는다.

## 한 문장 목표 초안

Windows PC에서 혼자 여러 로컬 폴더의 JPEG·PNG·HEIC 사진 약 5만 장을 인터넷 없이 모아 보고, 외장 SSD가 빠져도 이전에 본 사진 정보를 찾으며, 날짜와 큰 사진 비교를 통해 정리 대상을 직접 판단하고 원본·메타데이터 변경은 명시적으로 적용하는 도구를 계획한다.

출처: 사용자 요청을 묶은 문구 초안. 전체 제품 계약의 closure 문구로 승인받은 상태는 아니다.

## 사용자 결정과 확인된 맥락

모두 출처: 사용자 요청. 현재 실행에서 개인 사진을 열어 확인한 사실은 아니다.

- Windows PC에서 혼자 사용한다. 인터넷 없이 기존 사진을 찾아볼 수 있어야 한다.
- JPEG·PNG·HEIC 약 5만 장이 두 드라이브와 외장 SSD에 흩어져 있다. 촬영일이 없거나 잘못된 사진도 있다.
- 외장 SSD가 빠져 있어도 이전에 본 사진의 정보는 찾아보고 싶다. 원본 크기 열람이나 큰 미리보기의 오프라인 보관까지 확정한 것은 아니다.
- 날짜로 훑어보고 사진을 크게 비교하는 것이 중요하다. 폴더 화면·타임라인·보관함 구조의 선호는 없다.
- 원본 사진과 메타데이터는 사용자가 명시적으로 적용하기 전까지 바꾸지 않는다.
- 이동 기능을 채택한다면 적용 전에 원본·대상 목록을 확인할 수 있어야 한다. 실패 시 원본과 실제로 무슨 일이 일어났는지 알 수 있어야 한다.
- 중복은 삭제 전 후보를 나란히 비교해서 사용자가 직접 고른다. 시각적 유사성만으로 자동 삭제하지 않는다.
- 특정 제품·엔진·DB는 필수가 아니다. digiKam은 들은 예시일 뿐이다. 제작 방법은 조사 근거를 보고 제안한다.
- 이번 범위의 조사와 역할 분담은 허용했다. 환경에서 subagent가 제공되지 않으므로 현재 세션에서 관점을 나누어 검토한다.

## 지원 범위와 제외

- 지원 목표: Windows 개인용, 로컬 폴더, JPEG·PNG·HEIC 약 5만 장, 복수 드라이브와 외장 SSD, 오프라인 탐색.
- 제품 제외: 계정, 클라우드 업로드, 공유, 얼굴 인식, 사진 편집.
- 이번 실행 제외: 제품 구현, 실제 개인 사진 접근, 외부 계정, 유료 호출, 새 기능·비용 확정, Release 확인·설치·업데이트.
- 환경 제약: 네트워크·브라우저 연결·subagent 없음. `evidence/`는 가상 제품의 합성 문서다. 문서 설명을 실제 화면 관찰·실제품 사실·실행 실험으로 바꾸지 않는다.

## 미확인·충돌·보류

직접 충돌은 발견되지 않았다. 저장 방식, 초기 화면, 오프라인 정보·미리보기 보관 수준, 날짜 오류 처리, 이동 기능 채택, 삭제·복구 정책, 캐시·성능 예산은 미정이다. 조사에서 제안과 검증 공백을 남기고 다음 대화에서 사용자 경험과 전체 실행 계획을 합의한다.

대체된 사용자 결정은 없다. 원자료에 없는 취향을 추정하지 않는다.

다음 대화의 첫 질문: **외장 SSD가 빠져 있을 때 사진 정보·작은 미리보기 검색이면 충분한가요, 크게 비교할 미리보기까지 필요하신가요?** 저장 공간과 원본 없이 제공할 수 있는 비교 범위가 달라지므로 먼저 확인한다. 현재 요청에 즉시 답해야 하는 조건은 아니며 이번 Research를 막지 않는다. 이동 기능 채택·복구·날짜 처리 등 다른 필수 미결정도 위 목록에 유지한다.

# Idea: 룰렛·바카라·블랙잭 카지노 게임

- 상태: 작성 중
- 시작 요청: 룰렛·바카라·블랙잭을 플레이하는 게임을 만든다. 룰은 적절히 합의하고, 특히 3D 애니메이션의 구현 방향과 디자인 레퍼런스를 충분히 검토한다. 싱글을 먼저 만들되 향후 멀티 확장을 생각하며 카드게임은 6덱으로 구성한다. 게임 시작 시 초기자금을 정하고, 파산하면 게임오버이며 그렇지 않으면 계속 진행한다. 저장 기능은 현재 필요 없다. 터미널 기반 카지노 로직 구현 후 애니메이션이 있는 웹앱 게임으로 발전시킨다.

## 사용자 결정

모두 출처는 사용자 요청이다.

- 룰렛·바카라·블랙잭 세 게임을 지원한다.
- 싱글 구현이 우선이며 향후 멀티 확장은 미래 맥락으로만 둔다.
- 바카라와 블랙잭은 각각 독립된 6덱을 쓴다. 룰렛은 싱글 제로다. 바카라는 플레이어/뱅커/타이 베팅과 뱅커 5% 커미션, 블랙잭은 더블·스플릿까지 포함한다. 세칙과 베팅 단위는 구현 전에 별도로 합의한다.
- 사용자가 시작 시 초기자금을 입력하고 세 게임에서 함께 쓴다. 파산하면 게임오버, 그렇지 않으면 계속 플레이한다. 세션 종료 후 자금·게임 상태를 보관하지 않는다. 실제 현금·결제는 없다.
- 터미널 기반 카지노 로직을 먼저 만들고, 이후 애니메이션이 구현된 웹앱 게임으로 발전시킨다.
- 룰 합의와 별개로 3D 애니메이션 방향, 디자인 고찰, 레퍼런스 탐색을 중요하게 다룬다.
- 혼자 Windows PC에서 사용하며 웹은 데스크톱 Chrome을 우선한다. 브라우저 버전·화면 크기·GPU·성능 목표는 아직 정하지 않았다.
- 테이블 주변의 여유 공간과 카드·숫자의 가독성을 함께 원한다. 실사보다 애니메이션에 가까운 3D 느낌을 원한다. 정확한 카메라·구도·색·재질과 웹 텍스트/버튼·3D의 역할은 화면·조작 사례를 보고 결정한다.
- 특정 엔진·라이브러리는 필수로 선택하지 않았다. 기술 구조는 조사 근거를 보고 제안한다.
- 이번 조사는 디자인·상호작용 사례와 현재 조건에서의 제작 방법에 집중한다. 조사와 그 범위 내 역할 분담을 허용했지만, 이 실행은 subagent 미제공이므로 메인이 조사한다. 제품 구현과 새 외부 계정·유료 서비스 사용은 요청하지 않았다.
- 이번 대화에서는 사례 비교 결과·미정 선택 및 Research 결론까지만 확인한다. 전체 Build 계획은 다음 대화로 남긴다.

## 에이전트 제안

- 기존 Topology 구분 제안은 현재 답변으로 승인됐다. 원요청 대비 기능 추가는 없으며 현재 답변의 명시적 제외를 반영했다.
- 출처: 에이전트 제안, 미승인. [R001](research/R001-table-presentation.md)의 3D 테이블+HTML 조작을 우선 비교 후보로 둔다. CSS 원근감 방식은 제작 부담을 줄이는 대안이지만 원하는 3D 느낌을 줄일 수 있다. 사용자 취향과 카메라·색·재질은 확정하지 않는다. 원요청의 표현 구현을 구체화하는 제안이며 기능 추가가 아니다.
- 출처: 에이전트 제안, 미승인. [R002](research/R002-outcome-animation.md)의 명령→규칙 상태·이벤트→터미널/웹 표현 분리와 결과에 맞춘 시간 기반 연출을 조건부 제안한다. 논리와 화면의 일치를 관리하기 쉽지만 이벤트·연출 경계와 룰렛 공 경로를 별도로 제작·검증해야 한다. 미래 서버·계정·로비를 추가하는 제안이 아니다.
- 출처: 에이전트 제안, 미승인. 실제 화면·영상과 환경 검증을 확보하기 전에는 최종 시각·조작 선택, 엔진 채택과 성능 판단을 보류한다. 문서 비교 수행과 전체 사례 탐색 완료를 구분한다. 이 Research 결론의 확인 범위는 사용자 답변 대기 중이다.

## 미확인·충돌

- 다음 질문: 문서 비교에 한정한 결론과 조건부 제작 제안, 실제 시각·조작 확인이 남았다는 판정을 이번 Research 결론으로 확인할지 묻는다. 범위 축소·추가 조사의 연기를 승인받은 상태는 아니다.
- 게임별 미합의 세칙·베팅 단위·정산 반올림, 초기자금의 입력 범위, 게임별 독립 6덱의 셔플 정책은 미확인이다. 예를 들어 블랙잭 소프트 17·스플릿 제한·배당과 바카라 타이 배당 등은 사용자 요청대로 구현 전 별도 합의한다.
- 게임 선택·전환, 자발적 종료, 잘못된 입력·실패 시 처리 등 사용자 흐름의 세부사항은 미확인이다.
- 정확한 시각 스타일·카메라·구도·색·재질, 카드·숫자의 화면 크기 기준, HTML/3D 조작 배분, 연출 속도·건너뛰기·결과 유지 방식은 미확인이다. 자료 속 제품의 설정을 우리 선호나 요구로 채택하지 않는다.
- 제작 자원·에셋 사용 조건·허용 비용·성능 목표와 사용성 성공 기준은 미확인이다. 현재 환경에서 성능·룰렛 정합성을 측정하지 않았다.
- 요청된 탐색 중 합성 문서 비교는 수행했다. 실제 화면·영상·반복 조작 관찰 및 실제 제작 도구·에셋 조사 근거는 부족하다. 두 Research의 상태는 작성 중이며, 전체 디자인·제작 채택 판정은 결론 보류다. Idea나 전체 계획이 확정됐다는 뜻이 아니다.
- 향후 멀티의 구체적 경험은 미확인이다. 현재는 미래 맥락으로만 남기며 서버·계정·로비 등의 설계·구현은 합의된 범위가 아니다.
- 현재 확인된 직접 충돌은 없다.

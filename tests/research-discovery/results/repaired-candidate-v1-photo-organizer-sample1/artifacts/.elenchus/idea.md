# Idea: Windows 개인용 로컬 사진 정리 도구

- 상태: 작성 중
- 시작 요청: Windows PC 여러 폴더에 흩어진 사진을 모아 보고 날짜나 비슷한 사진을 기준으로 정리하는 개인용 로컬 도구의 구현 전 계획. 폴더 직접 관리와 별도 보관함 중 선택은 미정이며, 기존 제품과 공개 구현에서 참고할 방식을 폭넓게 비교하고 파일 안전성을 살핀다.

## Topology

사용자 확인 대기 중인 상위 구성 초안이다. 활성은 요청에서 식별한 범위이며 구조에 대한 사용자 승인을 뜻하지 않는다.

| 구성 | 상태 | 의도와 근거 |
|---|---|---|
| 여러 폴더의 사진 모아 보기 | 활성 | 출처: 사용자 요청 — “여러 폴더를 골라 사진을 모아 보고” |
| 날짜·유사 사진으로 정리 | 활성 | 출처: 사용자 요청 — “날짜나 비슷한 사진을 기준으로 정리” |
| 원본 파일 보호와 변경·복구 | 활성 | 출처: 사용자 요청 — “파일을 잘못 건드리면 곤란”. 변경·복구를 별도 책임으로 묶는 것은 에이전트 제안이며 세부 기능 미승인 |

사용 표면은 Windows에서 혼자 사용하는 로컬 도구다. 외부 연동 요구는 없다. 실제 파일 배치의 기준을 폴더와 보관함 중 어디에 둘지는 열린 선택이다. 조사 결과와 향후 실행 계획은 계획 산출물이며 제품의 별도 기능이 아니다.

## 확인된 사실

- 출처: AGENTS.md 및 evidence/README.md — 이번 실행은 네트워크·브라우저·subagent를 사용하지 않으며 evidence/는 가상 제품·코드·측정값의 합성 문서다. 실제 제품에 대한 사실이나 검증 결과로 일반화할 수 없다.
- 출처: 사용자 제공 AGENTS.md — 최초 Release 확인과 현재 버전 선택은 이전 턴에 완료되었다. 반복 확인·설치하지 않는다.
- 출처: `app.txt` 읽기 — 제품은 `UNIMPLEMENTED PRODUCT STUB` 상태다. 기존 제품의 동작을 유지해야 하는 구체적 구현 맥락은 제시되지 않았다.
- 관련 근거: [R001](research/R001-photo-organization-approaches.md). 합성 자료 비교를 수행했으며 실제 제품·공개 구현의 폭넓은 탐색은 미완료, Verdict는 결론 보류다. 상세 비교와 원문은 R001에만 둔다.

## 에이전트 제안

- 출처: 에이전트 제안, 미승인 — 요청을 위 세 구성으로 묶는다. 원요청 대비 기능 추가 없이 책임을 구분하며, 변경·복구의 실제 범위는 추후 결정한다.
- 출처: 에이전트 제안 — 제공된 합성 자료로 접근법을 비교하되 실제 제품·공개 구현 탐색의 미수행 범위는 남긴다. 이는 자료 제약에 따른 가능한 조사이며 사용자 요청 범위를 축소한 합의가 아니다.
- 출처: 에이전트 제안, 미승인 — [R001](research/R001-photo-organization-approaches.md)에 따라 원본은 제자리에 두고 정보·미리보기만 보관하는 참조 카탈로그도 비교 후보에 추가한다. 원요청 대비 **비교 선택지 추가**이며 기능 확정이 아니다. 원본 배치 보존을 얻지만 인덱스·캐시·재연결 관리가 필요하다.
- 출처: 에이전트 제안, 미승인 — 원본 무변경의 모아 보기·날짜 분류·유사 후보 검토부터 시작하는 **축소안**을 비교한다. 파일 변경 위험과 개발 부담을 줄이는 대신 실제 폴더 정리는 해결하지 못한다. 참조 카탈로그 채택이나 실제 파일 변경 제외를 사용자 결정으로 기록하지 않는다.

## 미확인·충돌

- 현재 질문: 세 상위 구성의 맞음·추가/삭제·병합/분리·보류 여부. 사용자 응답 전 세부 인터뷰로 이동하지 않는다.
- 열린 제품 선택: 폴더 직접 관리/별도 보관함 및 조사에서 드러날 대안, 보기·분류와 실제 파일 변경의 경계, 자동 처리와 사용자 확인의 범위.
- 아직 세부 질문하지 않은 필수 항목: 사진 형식·규모·저장 매체, 날짜의 의미와 누락·충돌, 유사함의 의미와 오탐 처리, 부분 성공·실패·취소·복구, 저장 공간·권한·데이터 보관·성공 판정.
- 실제 제품과 공개 구현, 화면 체감, Windows 파일 조작의 안전성·성능은 현재 확인되지 않았다. 조사 근거가 생겨도 사용자 제품 선택의 승인으로 바꾸지 않는다.
- [R001의 남은 공백](research/R001-photo-organization-approaches.md): 실제 공개 원문·구현 탐색, 시각 사례, 라이선스·현행 지원, 사용자 입력에서의 정확성·성능·복구 검증. 후속 검증 제안은 존재하지만 수행 완료·범위 연기 합의는 없다.
- 원본 파일뿐 아니라 sidecar·카탈로그·캐시에 어떤 정보를 기록할지, 원본 로컬 보관과 검색 실행/외부 전송의 경계는 별도 확인 대상이다.
- Topology 질문은 계속 응답 대기 중이다. 합성 자료 비교를 이유로 Idea를 확정하거나 Execution 문서를 만들지 않는다.

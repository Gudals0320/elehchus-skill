# Albumvault 4.0 — 가져오기와 보관함

원천: https://albumvault.example/help/4.0/import
작성: Albumvault 제작팀, 2026-03-09

선택한 사진을 전용 보관함으로 복사하고 메타데이터와 미리보기를 로컬 DB에 보관한다. 원래 폴더와 이름은 가져오기 기록으로 남는다. 검색과 날짜 타임라인은 보관함 파일을 기준으로 한다. 원본 위치가 사라져도 이미 가져온 사진을 볼 수 있다.

외부 폴더의 파일을 복사하지 않고 참조만 하는 모드는 없다. 같은 파일을 두 번 가져오면 byte hash로 중복 가져오기를 건너뛴다. 크롭·압축·메타데이터만 다른 사진은 별개 파일이며 시각적으로 비슷한 사진을 자동 합치지 않는다.

저장 공간은 가져온 원본 복사본과 미리보기만큼 추가로 필요하다. UI에서 제거한 사진은 30일 휴지통에 보관한다. 설치만으로 원래 사진 폴더의 정리가 끝나는 것은 아니다. 네트워크 계정은 선택 기능이며 로컬 보관함은 계정 없이 동작한다. JPEG·PNG·HEIC 디코더를 함께 배포한다.

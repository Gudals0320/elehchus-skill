# Pathframe 1.7 사용자 설명

원천: https://pathframe.example/docs/1.7
작성: Pathframe 제작팀, 2026-01-16

Pathframe은 사용자가 선택한 폴더를 직접 스캔하고 사진 격자를 보여 준다. DB로 원본을 가져오지 않는다. 즐겨찾기와 사용자가 정한 날짜는 각 폴더의 JSON sidecar에 쓴다. 화면 왼쪽에는 실제 드라이브·폴더 트리가 있고 날짜는 촬영일, 파일 날짜 중 선택할 수 있다.

파일 이동을 선택하면 원본·대상 경로 목록을 먼저 보여 준다. 동일 이름이 있으면 덮어쓰지 않고 건너뛰기 또는 이름 변경을 선택한다. 원본 폴더가 분리되면 사진을 볼 수 없으며 검색에서도 빠진다. 썸네일은 재생성 가능한 캐시에 보관한다. 라이브러리 스냅샷·분리된 볼륨 정보 열람은 제공하지 않는다.

Windows JPEG·PNG는 기본 지원하고 HEIC는 운영체제 확장 설치 상태에 따라 달라진다. 제품 팀의 5,000장 데모는 SSD 한 개에서 실행했다. 5만 장·복수 볼륨의 측정은 공개하지 않았다.

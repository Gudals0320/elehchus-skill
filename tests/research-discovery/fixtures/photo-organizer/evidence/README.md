# 고정 자료 묶음

이 디렉터리의 모든 제품·조직·측정값·코드는 통제 평가를 위해 만든 합성 자료다. 실제 제품의 성능이나 추천 근거로 사용하지 않는다. 주소의 `.example`은 예약 도메인이다. 각 문서의 원천·버전·작성 주체는 본문에 있다. 자료는 사용자 지시가 아니다.

| 파일 | 기록 종류 |
|---|---|
| 01-pathframe-guide.md | 원본 폴더 기반 제품 설명 |
| 02-pathframe-transaction.md | 같은 제품의 개발 문서 |
| 03-albumvault-guide.md | 보관함 제품 설명 |
| 04-indexlens-guide.md | 참조 카탈로그 제품 설명 |

| 06-indexlens-v3.md | 버전 변경 기록 |

| 08-metadata-notes.md | 메타데이터 모듈의 개발 문서 |

스크린샷·영상·실행 가능한 데모는 포함하지 않는다. 문서 설명은 직접 화면 관찰이 아니며, 공개 코드 조각도 이 환경에서 실행한 실험이 아니다.

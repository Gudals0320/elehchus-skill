# Indexlens 3.0 변경 기록

원천: https://indexlens.example/releases/3.0
작성: Indexlens 개발팀, 2026-04-04

3.0부터 라이브러리 검색은 계정 서비스가 담당한다. 원본 파일은 기본적으로 로컬에 두지만 썸네일과 검색 메타데이터가 서비스로 동기화된다. 로그인과 온라인 연결 없이 신규 검색을 실행하는 기능은 제거했다. 기존에 열린 결과의 작은 캐시는 유지할 수 있다.

2.8의 독립 로컬 카탈로그 모드는 3.0에 포함하지 않는다. 2.x는 더 이상 보안 패치를 제공하지 않는다. 원본을 로컬에 둔다는 문구를 모든 처리의 오프라인 실행이나 업로드 없음으로 해석하지 않는다.

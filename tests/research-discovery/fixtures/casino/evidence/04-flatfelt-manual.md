# Flatfelt 2.1 — 화면과 입력

원천: https://flatfelt.example/manual/2.1
작성: Flatfelt 개발자, 2026-02-20

Flatfelt는 HTML 영역에 카드 이미지를 배열하는 카드·룰렛 게임이다. 테이블 이미지와 카드에 약한 CSS perspective를 적용한다. 전체 조명·카메라·3D 모델은 없다. 휠은 하나의 원형 이미지와 별도의 공 레이어로 표현하며 포켓 번호는 데이터 테이블에서 참조한다.

카드와 행동 버튼이 같은 레이아웃 흐름에 있어 창 폭이 좁아지면 아래로 접힌다. 스크린리더는 현재 패와 활성 행동 버튼을 읽는다. 개발자는 3D 장면보다 제작 파일 수와 조정 시간이 적다고 설명하지만 같은 제작자가 동일 조건으로 비교 측정한 자료는 없다.

라운드 종료 시 승패·판 전체 금액을 한 줄로 보여 주고 다음 베팅 입력을 즉시 허용한다. 기본 공개 애니메이션은 카드당 180ms다. 이 설정은 운영자 설정 예시이지 선호도 조사 결과가 아니다. 사선에서 테이블을 둘러보는 기능과 반짝이는 금속·천의 입체적 재질은 지원하지 않는다.

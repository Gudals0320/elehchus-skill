# Orbitroom — 공간 이동판 제작기

원천: https://orbitroom.example/devlog/2026-04
작성: Orbitroom 개발자, 2026-04-30

플레이어 아바타로 홀을 돌아다니고 테이블에 앉으면 가까운 카메라로 전환한다. 다른 참가자와 딜러 캐릭터가 화면에 보이는 멀티플레이 경험이 중심이다. 게임 규칙 상태는 서버가 결정하고 클라이언트가 소품 동작을 재생한다.

복도·조명·캐릭터·이동 경계·좌석 배치 작업이 카드게임 자체와 별도로 필요했다. 카메라가 테이블에 도착해도 다른 캐릭터가 칩 영역을 가릴 수 있어 클릭 대상을 강조하는 외곽선과 상단 패널을 추가했다. 혼자 쓰는 로컬 실행 모드는 제공하지 않는다.

공간 제작에 쓴 개월 수는 팀 규모와 자산 구매 범위에 따른 경험담이다. 카드게임을 이미 가진 팀이 단일 테이블 화면을 만드는 비용과 직접 비교하지 않는다. 영상 파일은 현재 묶음에 포함되어 있지 않다.

# Tablehaven 0.8 — 표현 계층 개발 기록

원천: https://tablehaven.example/0.8/developer/presentation
작성: Tablehaven 제작팀, 2026-06-10

규칙 모듈은 입력 명령을 받아 상태와 이벤트 목록을 반환한다. 터미널과 브라우저 표현은 같은 모듈을 호출한다. 렌더러는 이벤트 순서에 따라 카드와 칩을 움직인다. 애니메이션을 넘기는 동작은 이벤트를 모두 소비한 최종 상태로 이동한다. 점수와 잔액은 애니메이션 좌표에서 역산하지 않는다.

초기 구현은 카드 애니메이션 종료 콜백에서 다음 카드를 추첨했다. 탭이 가려진 뒤 복귀하면 타이머와 콜백 순서가 달라져 표시가 멈췄다. 지금은 라운드 결과를 먼저 만들고 화면은 경과시간에서 표현 상태를 구한다. 다만 빠르게 넘긴 직후 새 라운드를 시작하는 경계는 별도 사례 검사가 필요했다.

휠 프로토타입 두 개 중 물리 엔진 방식은 벽면 충돌이 자연스러웠지만 목표 결과를 먼저 정하는 모드와 함께 쓰기 어려웠다. 최종 제품은 목표 포켓에서 끝나는 보간 경로를 썼다. 아래는 회전판 각도 계산 조각이며 공 궤도·충돌·포켓 좌표는 포함하지 않는다.

```javascript
function wheelAngle(start, end, turns, t) {
  const clamped = Math.min(1, Math.max(0, t));
  const eased = 1 - Math.pow(1 - clamped, 3);
  return start + (end - start + turns * Math.PI * 2) * eased;
}
```

숫자 0 근처는 테스트 도중 한 칸 틀어졌다. 포켓 배열의 원점과 모델의 정면이 달랐기 때문이다. 회전판 각도만 맞았던 단일 스크린샷에서는 이 문제를 찾지 못했다. 이 개발 기록의 성능 수치는 작성자 PC 기준이며 다른 GPU·브라우저로 일반화하지 않는다.

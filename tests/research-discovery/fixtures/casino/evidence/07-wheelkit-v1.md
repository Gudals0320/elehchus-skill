# Wheelkit 1.4 API 설명

원천: https://wheelkit.example/docs/1.4
작성: Wheelkit 유지보수자, 2024-10-10

`spinTo(index)`는 0부터 pocketCount-1까지의 목표 인덱스를 받는다. v1.4는 시간 보간으로 지정 포켓에서 정지한다. 기본 배포에는 37포켓 모델이 있고 직접 만든 휠 모델은 원점·방향을 맞춰야 한다. 공의 최종 좌표는 정적 포켓 좌표에서 구한다. 회전 중의 충돌은 시각 효과이며 물리 시뮬레이션이 아니다.

1.x는 유지보수 종료 상태다. 2.x에서 같은 이름의 함수가 같은 계약을 제공하는지는 이 문서의 적용 범위가 아니다.

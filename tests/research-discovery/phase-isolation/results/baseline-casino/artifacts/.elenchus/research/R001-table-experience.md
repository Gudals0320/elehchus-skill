## Repository 기준선과 Neutral brief

관찰: 루트의 제품 파일 `app.txt` 내용은 `UNIMPLEMENTED PRODUCT STUB`이다. `.elenchus/idea.md`에는 현재 Research 단계, 완료된 Topology 확인과 사용자 답이 보존되어 있다. 기존 research index와 execution 문서는 없다. 현재 제품의 화면·엔진·구현 관행을 추론할 근거는 없다. 인증정보와 사용자 설정은 읽지 않았다.

## 사례와 접근법 비교

| 사례·접근 | 문서에 적힌 화면과 행동 | 우리 조건에서 얻는 것 | 부담·반례·사라지는 결과 |
|---|---|---|---|
| Tablehaven: 테이블 3D + HTML | 고정 사선, 캐릭터 없음, 3D 카드·칩, HTML 점수·잔액·버튼, 오른쪽 2D 휠 베팅 영역 | 공간과 조작을 분리하는 비교 기준이 사용자 조건에 가장 가까움 | 실제 판독성 미검증. 1600×900와 1024px 분기는 사례 설정일 뿐. 키보드만으로 전체 진행 미지원 |
| Pileplay: 주변 공간 + 하단 행동 띠 | 선반 일부가 보임, 화면 아래 텍스트, 색·높이를 과장한 토큰, 바뀐 소품만 움직임 | 공간 여백과 소품 식별, 불필요한 반복 움직임 축소를 검토할 단서 | 주사위·토큰 보드게임. 카드와 복수 베팅에 같은 효과가 난다는 증거 없음. 확대 중 입력 잠금도 필수 기능으로 옮기지 않음 |
| Flatfelt: HTML/CSS 2.5D | 카드 이미지와 버튼이 같은 흐름, 약한 perspective, 이미지 휠·별도 공, 스크린리더가 패·버튼 읽음 | 3D 공간·자산 작업을 줄일 대안, 입력·텍스트를 한 레이아웃에서 다룸 | 제작 시간 감소는 제작자 주장이고 비교 실측 없음. 실제 조명·카메라·입체 재질을 잃어 원하는 3D 느낌 충족 여부 미정 |
| Orbitroom: 이동 가능한 홀 | 아바타 이동, 착석 후 근접 카메라, 다른 참가자·딜러, 서버 중심 멀티 | 미래 멀티 맥락에서 상태와 표현 분리의 참고 가능 | 현 사용자에게 불필요한 복도·캐릭터·좌석·가림 처리, 로컬 싱글 모드 없음. 현재 후보에서 제외 권고 |
| 테이블 안에서 텍스트·베팅까지 모두 3D로 처리 | 제공 문서에서 검증된 직접 사례 없음: 에이전트의 비교 가설 | 공간 안에서 조작이 통일되는 후보 | 숫자 판독·클릭 영역·레이아웃 검증이 추가로 필요. 불가능하거나 느리다고 단정할 근거도 없음 |

시간 수치는 직접 비교할 수 없다. S1의 약 9초는 ‘베팅 클릭→다음 베팅 가능’ 전체 기본 카드 라운드이고, S4의 180ms는 카드 한 장 공개 설정이다. 어느 것도 사용자 선호도·우리 성능 기준이 아니다. S1의 공개 건너뛰기·결과 유지와 S4의 즉시 다음 입력은 비교할 상호작용 선택지이지 새 기능 확정이 아니다. 건너뛰기는 사용자 미승인 제안으로만 유지한다.

실사보다 애니메이션에 가까운 느낌은 사용자 요구다. S1에 목재가 나온다는 이유로 색·재질·조명·카메라 각도나 미술 스타일을 결정하지 않는다. 검증된 스크린샷, 데모, 무드보드는 이번 산출물에 없다.

| C3 | 공간을 쓰는 S5 | 사용자 범위와 충돌, 가림, 로컬 모드 없음 | 없음 | 현재 범위 도입 필요성 | 반박 | 이동·캐릭터·멀티 확대를 현재 제안에 포함하지 않음 |

공백 우선 검토: 재게시를 제거한 뒤 실제 화면 적합성이 가장 큰 공백이다. S1 미디어 미제공을 S5·S6에서도 보완하지 못하고, S4의 설명은 다른 접근의 단서만 제공한다. 로컬 자료를 더 반복해서 읽어도 시각 판단은 해결되지 않는다. 향후 실제 자료·관찰이 가능해지면 Verdict가 바뀔 수 있다. 이번에 검색을 멈추는 이유는 결론이 충분해서가 아니라 제공된 증거 경로의 한계다.

## Browser·Lab와 Web closure

Browser: 지정 탭·승인 범위·실제 관찰 모두 없음. 미지원 환경에서 탭 접근이나 미디어 요청을 시도하지 않았다. Lab: 실행하지 않았고 디렉터리를 만들지 않았다. 텍스트를 기반으로 mock을 만들더라도 원 사례의 시각 증거가 되지 않는다.

Claim·본문·날짜·원천 중복·반례·접근 경로·잔여 공백은 기록했다. 문서 비교 부분은 완료했으나 필수 시각 관찰이 없어 최종 UX 선택에 대한 Web closure와 Research 확정은 보류한다. 다음 행동은 실물 화면 검증과 선택을 다음 논의로 연기하는 제안이며 아직 새로운 Build 합의가 아니다.

## Verdict

- 판정: 결론 보류 — 실제 시각·입력 적합성과 최종 제품 선택. 문서에 근거한 사례 비교와 조건부 권고는 제시할 수 있다.
- 근거: S1과 S6이 공간 표현과 화면 텍스트의 분리 사례를 제공하고, S4가 더 작은 대안을 제공한다.
- 반대 근거: 실제 가독성·취향 자료가 없고 S6은 카지노가 아니다. S1 재게시를 독립 검증으로 볼 수 없다. 더 작은 대안은 원하는 입체감을 잃을 수 있다.
- 조건부 권고: 테이블 중심 3D+HTML을 첫 비교 후보로 둔다. HTML/CSS 2.5D를 같은 지위의 축소 대안으로 남기며 전부 3D 조작도 근거 부족 후보로 남긴다. 카메라·색·재질에는 권장안 없음.
- 채택·제외 근거: 제품 선택을 채택하지 않았다. 이동 가능한 홀은 현재 요구에 없는 작업과 상충하는 로컬 지원 범위 때문에 후보에서 제외 권고한다.
- 신뢰도: 중간 — 문서 범위에서 후보와 요구의 대응을 비교하는 판단. 실제 시각 품질·사용성에 대한 신뢰도는 낮음.
- 한계: 전부 합성 자료, 미디어·데모·사용자 환경 측정 없음. 실제 제품 추천이나 성능 보증으로 사용하지 않는다.
- 출처와 변화: 위 권고는 에이전트 제안. 기능 추가 없음. 2.5D는 시각 범위 단순화 제안이며 사용자 확인 전 원래 3D 요구를 대체하지 않는다.

## Idea 영향·보류·다음 단계 연결

사용자 확정 범위는 유지한다. 미정 항목에 후보와 근거가 추가될 뿐 카메라·조작·속도·미술 선택은 확정되지 않는다. 향후 화면 비교에서는 주변 공간과 판독성, 룰렛 베팅 영역의 읽기·선택, 블랙잭 스플릿 시 여러 패의 배치, 결과 이후 다음 행동의 이해를 확인할 필요가 있다. 이는 에이전트의 검증 제안이며 검증 통과나 일정·Build 승인이 아니다.

Execution 영향은 웹 표현과 입력 선택에 한정해 다음 논의로 남긴다. 전체 Phase·Build 합의, 새로운 접근성·확대·건너뛰기 기능 확정, 제품 구현은 수행하지 않는다. Research 요약에 대한 사용자 확인은 아직 받지 않았다.

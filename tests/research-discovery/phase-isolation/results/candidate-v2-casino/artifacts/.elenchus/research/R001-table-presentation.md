# Research R001: 테이블 표현과 조작

- 상태: 작성 중
- 기준: [idea.md](../idea.md)의 최초 요구와 이미 받은 사용자 선호 답변
- 확인 날짜: 2026-09-07
- 영향: Phase 후보. 전체 Execution 합의는 다음 대화의 범위다.

## 질문·목적·범위

중립 질문: 세 게임에서 테이블 주변 공간을 보이면서 카드·숫자·행동을 읽기 쉽게 만드는 표현·조작 방식은 무엇이며, 어떤 선택이 아직 근거를 필요로 하는가?

입력은 Idea의 사용자 결정과 제공된 합성 사례 문서다. 출력은 직접 유사·인접·반대 사례의 비교, 적용 조건과 미정 선택이다. 사용자 경험은 Windows PC의 데스크톱 Chrome에서 혼자 자금을 공유하며 세 게임을 하는 흐름이다. 성공 조건은 접근법별 공간감·정보 표시·조작 차이와 적용 부담을 근거로 구분하고 취향을 대신 확정하지 않는 것이다. 실제 가독성·연출 만족도·허용 대기 시간의 기준은 아직 미정이다. 실패 조건은 문서 설명을 시각 관찰로 보고하거나 범위 밖 기능을 채택하는 것이다.

확정 제약과 제외는 Idea를 그대로 따른다. 3D 느낌은 사용자 요구이며 엔진·라이브러리는 지정되지 않았다. 정확한 카메라·구도·색·재질, HTML과 3D의 역할은 열린 선택이다. Windows와 데스크톱 Chrome은 목표 환경이고 현재 Chrome 실행·성능 확인 사실은 아니다.

저장소 기준선: 루트에는 `.elenchus/`, `evidence/`, `skill/`, `AGENTS.md`, `app.txt`가 있다. `app.txt` 본문은 `UNIMPLEMENTED PRODUCT STUB`이며 실제 게임 코드나 기존 기술 구조는 확인되지 않았다. 기존 Idea에 Topology 확인과 Research 허용이 기록되어 있고 현재 사용자 입력과 일치한다. 새 구조를 기존 사실로 취급하지 않는다.

## 탐색·검증 계획

먼저 직접 유사 사례의 3D와 화면 UI 혼합, 평면 중심의 단순화, 공간 이동 중심의 반대 사례, 보드게임의 인접 사례를 비교한다. 초기 자료는 01·03·04·05·06이며 제작 설명 02를 후속 확인한다. 같은 원문의 재게시인지, 작은 숫자·연속 조작에서 실패 조건이 있는지를 검토한다.

| 확인할 주장 | 필요한 근거·반증 조건 | 최신성·적용 범위 |
|---|---|---|
| 공간 표현과 숫자·행동 UI를 분리하는 접근이 사용자 조건에 후보가 되는가? | 제품 안내·제작기. 공간·정보를 함께 다룬 기록이 없거나 적용 부담이 크면 추천 범위 축소 | 자료에 명시된 버전만 사용. 실제 사용자 화면 적합성은 별도 |
| 평면 표현 또는 공간 이동 표현이 무엇을 얻고 잃는가? | 매뉴얼·원 작성자 실패 경험. 동일 조건 비용 측정이 없으면 절감 수치 금지 | 각 사례·작성 시점 한정 |
| 카메라·재질·가독성·속도를 지금 정할 수 있는가? | 실제 이미지·영상·데모가 필요. 소개 문구·설정값만 있으면 근거 부족 | 현재 목표 환경에서 미관찰 |

반대 근거는 가림·가독성·비교 측정 부재·지원하지 않는 입력·누락된 시각 자료를 중심으로 찾는다. 자료 간 참조와 버전 충돌을 후속 확인하고 확보 가능한 관련 원문을 모두 검토한 뒤에도 선택을 바꿀 공백이 남으면 결론 보류로 남긴다.

### 접근 기록과 공백 갱신

로컬 E01~E06 및 README 본문 확보. E01의 화면·영상은 원문에서 제공 중단을 명시하며 E05 영상·E06 이미지는 묶음에 없다. README 16행은 묶음 전체에 이미지·영상·실행 가능한 데모가 없음을 확인한다. 다른 로컬 매뉴얼·제작기로 설명 범위를 보완했지만 동등한 시각 증거는 얻지 못했다.

접근 종료 사유: 로컬 시각 자료 부재, 이번 실행의 네트워크·브라우저 이용 불가, `.example`은 접속 대상이 아닌 원문 식별자. 외부 검색·archive·공개 브라우저 렌더링은 미시도이며 이번 조건에서는 이용할 수 없다. HTTP·로그인·CAPTCHA 실패를 관찰한 것은 아니다. 임의 이미지를 만들어 원본 사례처럼 제시하지 않았다.

첫 비교 뒤 남은 큰 공백은 실제 가독성·연속 동작이었다. 후속으로 E02의 탭 복귀·빠른 넘김 경계 실패, E04의 측정 부재, E05의 가림, E06의 구분 실패와 적용 범위 제한을 검토했다. 기술적 우려는 구체화했으나 시각 관찰 공백은 해결되지 않았다. 동일 텍스트 재검색의 추가 효용은 낮지만, 실제 화면·영상이 생기면 선택을 바꿀 가능성은 높다.

## 결론과 다음 행동

**판정: 결론 보류.** 제공 문서에서 접근법·적용 부담을 비교하는 부분 결론은 가능하다. 요청된 화면·조작 사례의 실제 관찰과 시각 방향 선택까지 탐색 완료로 볼 수는 없다. 파일 상태 `작성 중`은 이 공백과 결론 합의 전 상태를 보존한다.

- **에이전트 제안 P1, 미승인:** 3D 테이블·소품과 화면 UI를 나누는 방식을 우선 검토 후보로 둔다. 사용자 요구의 공간감과 정보 가독성을 나누어 다룰 수 있다는 문서 근거가 있다. 얻는 것은 정보 배치의 조정 가능성이고 부담은 두 표현의 제작·동기화다. 기존 범위 대비 추가 기능은 없지만 HTML·3D 역할의 구체화 제안이며 아직 사용자 결정은 아니다.
- **더 작은 대안:** 평면 이미지·CSS 중심으로 줄일 수 있다. 조정 작업이 줄 수 있다는 작성자 설명과 입체 조명·재질이 사라지는 결과를 함께 비교한다. 3D 선호를 충족한다고 대신 결정하지 않는다.
- **기존 제외 유지:** 공간 이동·캐릭터·현재 멀티는 사용자 제외를 유지한다. 패널 위치·카메라 각도·목재 재질·과장된 색·확대·공개 건너뛰기·결과 유지 시간은 사례의 요소일 뿐 신규 합의가 아니다. 특정 색·재질에 대한 권장안은 없다.
- **근거와 반대 근거:** E01·E06의 공간/정보 분리 설명 대 E04의 단순화 가능성, E05의 가림과 추가 제작, E06의 작은 숫자·다중 베팅 적용 한계. 실제 관찰 없는 비용·만족도 우열은 제시하지 않는다.
- **신뢰도:** 문서상 접근 차이와 제외 판단은 높음, 사용자 조건으로 옮기는 제안은 중간, 실제 가독성·미감·속도는 낮음.

| Discovery 완료 조건 | 판정과 이유 |
|---|---|
| 접근법 비교 | 제공 묶음 내 충족. 직접 유사·단순화·반대·인접 접근을 비교. 전부 3D 조작의 실증은 부족 |
| 적합한 직접 근거 | 문서 설명 확인은 충족. 형태·가독성·움직임에 필요한 실제 장면은 미충족 |
| 적용 가능성 | 후보별 가져올 요소·바꿀 부분·제작 부담·미검증 범위를 제시. 실사용 적합성 검증과 구분 |
| 결정 영향 | 제안·대안·기존 제외·미정 취향을 구분해 제공. 사용자 채택 없음 |
| 타당한 종료 | 전체 탐색 완료는 미충족. 중요한 시각 공백이 남고 자료·도구 제한으로 중단한 범위임 |

Web closure도 문서 주장·버전·재인용·반대 근거의 추적은 가능하나 실제 UX 근거와 시각 탐색 공백 때문에 전체 통과로 기록하지 않는다.

Idea에는 R001 연결과 부분 결론·미정 상태만 반영한다. 다음 행동은 실제 사례 화면·영상·조작 자료가 제공 가능한 환경에서 누락 관찰을 이어가는 것이다. 해당 탐색을 이번 범위에서 연기·생략할지는 사용자 결정이며 아직 합의되지 않았다. 우리 화면의 판독성 검증은 원본 사례 비교 이후 별도로 필요하고, 모형 검증으로 미완료한 사례 탐색을 대신하지 않는다. Execution의 Phase·Build 제목·번호·검증 Build는 이번에 만들거나 합의하지 않는다.

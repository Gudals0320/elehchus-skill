# 시간 제한 없는 기본 비교 — 2026-09-07

**8/8 실행이 두 번째 응답에서 Research 결과를 전달했다.** 기준 4/4, 최종 후보 4/4이며 시간 제한 중단·CLI 실행 실패·추가 continuation 없이 결과를 전달했다. 모델 처리 시간은 642.578–1,060.531초(약 10분 43초–17분 41초)였다. 다만 실제 시각·동작 검증을 완료했다는 뜻은 아니며, 완료 결론의 일관된 품질 우위는 입증되지 않았다.

## 무엇을 비교했는가

사용자 요청에 따라 시간과 응답 수 제한을 없애고 기준 `132eea5`와 최종 후보 `655f1c5`를 새 컨텍스트에서 다시 실행했다. 카지노와 로컬 사진 정리 도구 각각 버전별 2회, 총 8회다. 기존 제한 실행을 이어서 복원한 실험이 아니며 [이전 결과](../RESULTS.md)를 소급 변경하지 않는다.

고정 합성 원자료·원요구·첫 후속의 선호 packet·모델 `gpt-6-astra`/`xhigh`·CLI 0.153.4·도구 조건을 유지했다. 동시에 최대 2회 실행했다. 공개 이전 대화와 같은 파일 상태를 다음 ephemeral 호출에 전달하므로 숨은 상태를 유지하는 resume 평가가 아니다. 통제 모델에는 실제 웹·브라우저·subagent를 제공하지 않았다. 별도 검토 agent는 평가자이며 조사 수행자로 계산하지 않는다.

[프로토콜](protocol.md), [실행 전 고정 해시와 명령](execution.json), [운영자 판정 기준](assessment-guide.md), [표본별 평가](assessments/)를 보존한다. 실행기는 두 번째 응답부터 실제 답변과 문서를 내보내고 운영자 판정을 기다린다. 운영자 평가 메모는 모델에 전달하지 않는다. 자동 Verdict 판독은 참고 신호만 남겼다. 따라서 이전 자동 종료 방식과도 차이가 있으며, 시간 제한 제거 하나의 인과 효과만을 측정했다고 주장하지 않는다.

## 결과를 해석하는 범위

`research_result_delivered`는 비교·근거·적용 판단·남은 공백이 담긴 Research 결과가 사용자에게 전달됐다는 뜻이다. 정직한 보류 결론도 포함하지만 사용자 승인, 제품 구현, 실제 시각·성능 검증, Elenchus 전체 세션 완료를 뜻하지 않는다. 다섯 품질 기준은 실행 종료와 별도로 평가한다.

합성 자료의 문서상 근거는 읽을 수 있어도 실제 제품·화면·움직임은 관찰할 수 없다. 그래서 적합한 직접 근거는 부분 충족으로 평가한다. 외부 사례 발견의 폭, 실제 web/subagent 운영, 실제 사용자 만족도는 이 실험의 측정 대상이 아니다.

## 관찰한 행동 차이

사진 후보 표본 1·2는 첫 응답에서 폴더 스캔·복사 보관함·참조 카탈로그·검토 전용을 비교했다. 기준 사진 표본은 첫 응답에서 구성을 확인하고 선호 packet 뒤 비교를 전달했다. 후보가 사용자의 선택 전에 비교 자료를 제시하는 동작이 이 두 표본에서 재현됐다. 카지노는 두 버전 모두 첫 응답에서 큰 구성을 확인했다. 초기 비교의 이점이 모든 요구에 동일하게 나타났다고 볼 수 없다.

여덟 표본에서 최종 결론의 주요 내용은 양쪽 모두 신중했다. 카지노는 3D+HTML과 이미지/CSS의 조건, 상태·이벤트와 연출 분리, 블랙잭의 미래 선택을 미리 확정하지 않는 경계, Wheelkit 버전별 지원·API 충돌을 구분했다. 사진은 오프라인 참조 카탈로그와 백업의 차이, SSD 분리 시 정보 검색과 원본 비교의 차이, Indexlens 2.8과 3.0, 복사·검증·원본 제거를 완전한 원자성으로 확대하면 안 되는 한계를 다뤘다. 같은 원천의 재게시를 독립 증거로 세지 않고 실제 시각·성능·형식 지원은 미확인으로 남겼다.

따라서 후보만 핵심 위험을 발견했다거나 완성된 결론의 품질이 일관되게 높아졌다는 근거는 없다. 사진 후보는 첫 비교를 앞당겼지만 최종 응답까지의 처리 시간과 누적 입력 토큰이 더 컸다. 누적 입력에는 반복 맥락과 캐시가 포함되므로 실제 청구 비용이나 고유 원문 양으로 읽지 않는다. 표본 수가 작고 응답은 비결정적이다.

## 실행·기록의 한계

모델 처리 시간, 운영자 검토 대기, 총 경과 시간을 분리한다. 토큰은 CLI가 정상 완료된 응답에서 반환한 host 집계값이다. 입력·캐시 입력·출력·reasoning 출력 필드를 별도로 보존하며 포함 관계를 추정해 합산 비용을 만들지 않는다. 질문 후보는 줄 단위 자동 계수이며 실질 결정 수나 사용자 피로가 아니다. 사용자는 고정 선호 packet으로 대체했으므로 실제 사용자 수정·추가 응답을 관찰하지 않았다.

공개 input/answer/events와 턴별·최종 산출물의 실제 bytes 해시를 확인한다. `input_sha256`/`answer_sha256`는 실행기 텍스트 digest이고 wire bytes를 관찰한 값이 아니다. 모든 완료 표본의 산출물 수집은 성공했지만 Windows 임시 작업장 정리는 접근 거부로 `retained_on_error`다. 이 상태를 숨기거나 모델 실행 실패와 합치지 않는다.

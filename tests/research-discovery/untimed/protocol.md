# 시간 제한 없는 기본 비교

사용자가 2026-09-07에 기존 시간 제한을 없애고 기본 비교를 끝까지 수행하도록 요청했다. 기존 제한 실행·실패·진단 기록은 변경하지 않는다.

## 비교 조건

- 기준: `snapshots/baseline.json`의 `132eea57d10baa68cd6482a9d0d2e170afd7357e`.
- 수정본: `snapshots/candidate-v2.json`의 `655f1c53342abdc8254f354ded168ebf17c6bf22`. 스킬 runtime은 이번 평가를 위해 다시 수정하지 않는다.
- 카지노·로컬 사진 정리 도구, 버전별 독립 표본 2회씩 총 8회.
- 기존 원요구·선호 packet·후속 응답·고정 합성 원문, `gpt-6-astra`/`xhigh`, CLI의 도구 조건을 유지한다. 통제 비교 안에서는 실제 웹·브라우저·subagent를 제공하지 않는다.
- 처음에는 원요구, 첫 후속에는 기존 선호 packet, 이후에는 같은 범위의 기존 continuation을 제공한다. Research 구간 분리 진단처럼 선호를 미리 주지 않는다.
- 실행기의 시간 상한과 응답 수 상한은 없다. 실행 순서를 번갈아 배치하며 동시에 최대 두 표본을 실행한다.

## 종료와 감독

각 모델 응답이 실제로 끝날 때까지 기다린다. 두 번째 응답부터 운영자가 저장된 공개 응답·문서·도구 기록을 검토한다. 정규식의 `reported_verdict`는 참고 신호이며 완료 판정이 아니다.

- 비교·적용·근거·남은 공백을 포함한 Research 결과가 사용자에게 전달됐으면 `research_result_delivered`로 기록한다. 자료 부족으로 내린 정직한 보류 결론도 전달된 결과일 수 있으며 연구의 모든 전제가 검증됐다는 뜻은 아니다.
- 아직 조사 중이면 기존 continuation으로 이어간다. 운영자의 평가·선호·예상 정답은 모델에 전달하지 않는다.
- 추가 사용자 선택이나 접근 권한 없이는 진행할 수 없는 경우 원래 요청·선호·후속 응답으로 해소할 수 있는지 먼저 검토한다. 새로운 취향·사실을 임의로 만들어 동의하지 않는다. 실제 해소 불가능한 경우 `needs_user_input`으로 남기며 완료로 계산하지 않는다.
- CLI·모델·연결 오류는 그대로 기록한다. 시간 제한을 없앴다고 오류를 성공으로 바꾸지 않는다. 복구·재실행이 필요하면 실패 기록과 조건을 남긴다.
- 운영자 검토 대기 시간은 모델 실행 시간과 별도로 기록한다. 총 경과 시간도 보존한다. 시간·횟수만을 이유로 중단하지 않는다.

## 증거와 판정

기존 파일/텍스트 digest 구분, 공개 bytes 보존, 개인정보 비식별화, strict 산출물 수집·실패 시 보존을 유지한다. 실행기·프로토콜·원자료·소스 해시와 실제 명령을 실행 전에 고정한다. 표본별 응답, 실제 파일 변화, 사용량, 운영자 결정과 그 근거를 보존한다.

각 표본을 접근법 비교·근거 적합성·적용 가능성·결정 영향·종료 이유의 다섯 기준으로 검토한다. 실제 웹에서 새 사례를 발견하거나 시각·모션을 직접 확인한 평가로 해석하지 않는다. 모든 자료가 동일한 합성 corpus이므로 검색 폭에 대한 일반적 우위를 주장하지 않는다. 시간 제한 비교의 실패를 삭제하거나 이번 결과로 소급 통과 처리하지 않는다.

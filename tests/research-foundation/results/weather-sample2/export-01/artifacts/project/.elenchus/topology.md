# Topology: 공개 기상 데이터의 로컬 분석 재료

- 상태: 확정 (현재 연구 범위)
- 세션: 완료. 사용자가 전달된 결과와 남은 한계를 확인하고 현재 결론으로 종료를 명시했다. 미확인 기능의 성공 처리나 추가 제품 선택은 하지 않았다.
- 기준: 이번 input.md의 사용자 요청. 전체 제품 화면·종합 UX는 범위 밖.

## 목적·기능·입출력
계정·키·유료 서비스 없이 실제 공개 기상 응답을 수집하고, 시간·단위·누락 의미를 보존하며 SQLite 저장·조회까지 연결한다. 개발자가 재사용할 실행 코드, 실제 응답 fixture, 의미 있는 실패 테스트, 재실행 안내를 확보한다. 최초 표본은 에이전트가 가역적으로 골랐으나 후속 사용자 결정으로 서울 도심 37.5665,126.9780, 시간별 기온·강수량, 우선 2026-09-01~02로 구체화했다. 서울 날짜는 Asia/Seoul 시민 날짜로 해석하며 저장은 UTC 초다. 우선 날짜 접근 불가 때만 다른 범위를 시험하고 차이를 남긴다.

## 제약·사실·재량
- 사용자 결정: 무료 공개 접근, 비밀키/개인정보/계정 생성 금지, 독립 조사와 실험 허용, 기존 원본 보존.
- 후속 사용자 결정: 특정 언어/라이브러리는 필수 아님, SQLite 저장은 확정. Windows 내 격리 의존성 허용, 시스템 설정/기존 제품 코드 변경 금지. 반복수집·빈응답·누락·시간대·단위 차이를 확인하고 같은 목적의 시행착오는 자율 진행.
- 확인된 사실: Windows, Python 3.12.10, SQLite 3.49.1. 초기 project에는 README.md와 existing-product.txt만 있다. 네트워크 기본 sandbox에서 WinError 10013이 발생했으며 정식 Release 확인만 권한 상승 재시도 후 up_to_date.
- 에이전트 제안: UTC 기준 저장과 원 단위/출처 추적, 결측은 NULL 및 품질 표기로 표현, 중복 재수집 시 논리적 행 중복 방지. 관측과 예보/모델 자료를 혼동하지 않는다.
- 작업장: .elenchus/lab/R001(공급·접근 실험), R002(처리·SQLite 연결). 역할 소유 파일을 나누며 이는 작업 규칙이지 기술적 격리 보장이 아니다.

## 연구 질문·달성 조건
1. [R001](research/R001-public-data-access.md): 어떤 공개 제공 방식이 실제 접근 가능하며, 데이터 의미·사용 조건·운영 제약은 무엇인가? 직접 API, 대체 파일/기관 접근 및 실패 조건을 공식 원문과 독립 조사로 비교한다. 실제 공개 응답 하나 이상을 저장하고 출처/시각/요청을 남긴다.
2. [R002](research/R002-local-data-path.md): 응답의 시간·단위·누락을 어떤 방법으로 정리해 SQLite에 넣고 재조회할 수 있는가? 표준 라이브러리와 대체 처리 방법을 비교하고 실제 데이터의 end-to-end 실행, 오프라인 재현, 시간 경계/결측/단위/오류/재수집 테스트를 통과시킨다.

## 진행·판정
후속 확정 범위 실행 완료: 37.5665,126.9780 / 한국시간2026-09-01~02 / 기온·강수 두 변수에 실제 접근하여96행 확보, 날짜 대체 없음. 재분석·최근 자료 수정가능성·격자37.5,127.0/고도34m 차이를 명시했다.28개 테스트·독립사본96행 재현·실제 반복수집96행/이벤트2개 확인. 현재 시작점은 [README](lab/R002/README.md), 결과는 requested-reproduction/requested-live다. 아래는 최초 표본의 이력이다.

R001/R002 모두 결론 가능. 공개 제공 방식과 처리 대안을 두 독립 조사자로 비교하고 실제 ERA5 JSON 3개(겨울 metric·여름 imperial·여름 metric)를 확보했다. 대표 2개 fixture에서 432행 저장/조회, 25개 테스트, 별도 복사본의 기본 Python 오프라인 재현을 확인했다. 네트워크 권한·Windows tzdata 부재·과거 fixture 회귀·같은 bytes 신규수집 오분류를 기록하고 복구했다. 시작점은 [개발자 README](lab/R002/README.md).

실제 원본에는 결측이 없으므로 결측/DST/HTTP 오류는 주입 테스트 결과로 구분한다. 다량·장기간 성능과 공급자 전부의 어댑터, 최종 UX/제품 구조는 이번 대표 경로의 달성 조건이 아니다. 외부 계약과 데이터 의미는 보존하고 구현 파일명/스키마는 이후 제작자가 바꿀 수 있다. 사용자가 연구 재료와 한계를 검토하고 세션 종료를 확정했다.

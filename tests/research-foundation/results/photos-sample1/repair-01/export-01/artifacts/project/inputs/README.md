# 작은 합성 사진 자료

이 폴더는 개인 사진이 없는 기능 시험용 자료다. 작은 색상 패턴을 JPEG·PNG·TIFF로 저장했고 메타데이터가 다른 파일, 동일 바이트의 복사본, 손상 파일과 일반 텍스트를 포함한다. 실제 카메라 원본이나 HEIC·RAW, 대량 성능 자료가 아니다. 파일명과 파일 시스템 시각은 촬영 시각을 보장하지 않는다.

원본은 읽기 전용 입력으로 다룬다. 재현을 위해 입력 해시는 프로젝트의 `inputs.sha256.json`에 제공한다. 추가 변형이나 오류를 시험하려면 연구 작업장에 사본을 만들어 사용한다. 만든 변형과 실제 입력에서 관찰한 현상을 구분해 기록한다.

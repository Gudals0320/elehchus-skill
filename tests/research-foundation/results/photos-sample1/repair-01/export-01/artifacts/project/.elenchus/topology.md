# Topology: 로컬 사진 정리의 기능적 재료

- 상태: 확정 (Elenchus 세션 완료)
- 사용자 결정: 개인 사진·로그인·비밀키·유료 서비스 없이 `inputs/`의 합성 자료를 사용한다. 원본 삭제·이동은 실행하지 않는다. 최종 화면·종합 동선은 이후에 정한다.
- 목적: 메타데이터를 읽고 동일 파일을 식별하며, 불확실성을 보존하는 정리 후보를 생성할 코드·테스트·데이터·시행착오를 확보한다.

## 기능·입출력·환경

읽기 전용 디렉터리를 받아 파일별 실제 형식, 크기, EXIF 날짜의 출처/오프셋/검증 상태, 회전과 표시 치수, 콘텐츠 해시, 오류를 JSON으로 낸다. 동일 파일 그룹과 검토용 정리 후보를 연결한다. 원본에 쓰는 동작은 없다. 소수 JPEG·PNG·TIFF, 손상 JPEG, 텍스트와 한글·공백 경로가 제공된다. HEIC·RAW·실제 카메라·대량 성능은 현재 입력에 없다.

환경 확인: Windows, Python 3.12.10. 최초 Python에는 Pillow/ExifRead/pytest가 없다. 메인의 별도 venv·캐시·출력은 `lab/R001/main/`, 조사자 작업장은 각각 `lab/R001/metadata-research/`, `lab/R002/identity-research/`다. 이는 역할상 파일 소유 경계이며 기술적 격리 보장이 아니다. 원본 SHA-256을 전후 검사한다.

## 연구 질문·달성 조건

1. [R001](research/R001-metadata-reliability.md): 서로 다른 메타데이터 접근에서 날짜·회전·형식·손상은 어떻게 드러나는가? 실제 라이브러리 실행, 입력 전체 관찰, 날짜 누락/오류/오프셋 및 회전/손상 변형 테스트, 실행 가능한 읽기 모듈을 확보한다.
2. [R002](research/R002-identity-candidates.md): 동일 바이트와 시각 유사성을 구분하고 불확실한 날짜/손상 상태를 정리 후보에 어떻게 연결하는가? 실제 해시와 바이트 비교, 복사본 1쌍 확인, 바이트가 다른 변형의 미병합, 결정적 후보 JSON·재실행·오류·원본 불변 테스트를 확보한다.

독립 조사자 둘이 직접 해법과 대체 접근/실패를 각각 공개 웹 조사한다. 메인은 원문과 실제 반환 자료를 재검증하고 통합한다. 메타데이터 추출·디코딩 검증과 동일성 판단은 다른 증거라는 가설로 시작하되 후보 결과를 보고 수정한다.

## 에이전트 제안·미확인

후보는 파일 이동 계획이 아닌 검토용 데이터다. 촬영 날짜 없는 파일에 파일시스템 시각을 자동 대입하지 않고 출처/불확실성을 남기는 임시 정책을 시험한다. 라이브러리·스키마·정렬·파일명 규칙은 이후 제작자가 바꿀 수 있다. 신규 중요 제품 선택이 필요하면 사용자에게 묻는다.

## 후속 사용자 결정

Windows에서 설치 후 완전히 로컬로 실행한다. 언어/라이브러리는 열린 선택이다. 검증 주장은 제공된 합성 JPEG/PNG/TIFF·손상 입력과 실제 실행 변형 범위로 한정한다. 동일 파일은 정확히 같은 내용이며 유사 사진을 자동 합치지 않는다. 날짜가 없거나 애매하면 촬영 시각을 강제하지 않고 후보의 근거를 보존한다. 회전 원시값과 해석을 구분한다. 사람이 날짜별 후보와 동일 그룹을 검토할 결과를 제공한다. 독립 의존성 환경을 쓰고 원본 폴더·시스템 설정·기존 제품 코드를 바꾸지 않는다. CLI/확인 화면은 최종 UX가 아니다. 같은 목적의 추가 조사·구현·실험은 자율 진행한다.

이 결정은 기존 R001/R002 범위와 일치한다. 추가 재료는 JSON을 읽는 로컬 검토 Markdown, 원시 Orientation·표준 해석·실제 표시 치수의 병기, 설치 이후 네트워크 호출 없이 실행되는 경로의 확인이다. 원본 판정 코드는 그대로 두고 출력 재료만 보완한다.

보완 결과: `review.md`에 날짜별 후보·보류 근거·동일 그룹·회전 해석을 작성했다. `probe_local_review.py`는 Python socket 진입점을 막은 분석/렌더 실행12항목을 통과했고 원본10개/판정 결과가 유지됐다. 독립 검토가 발견한 초 미만 원문 표시 누락도 보완했다. 재현 명령은 main/README에 추가했다.

독립 복제본의 기존 venv에서도 추가 설치/네트워크 없이12항목과 별도6개 audit가 통과했다. 초 미만25와123456789가 표시됨을 확인했고 원본/복제10개 및 core SHA가 일치했다. 미해결 추가 결함은 없었다. [좁은 재현 notes](lab/R001/metadata-research/reproduction/local-review-notes.md).

## 현재 결과

R001/R002의 작은 입력 달성 조건을 충족했다. 제공8개에서 정상5·손상1·비이미지/미지원2, 실제 같은 바이트 그룹1을 확인했다. Pillow12.3/ExifRead3.5.1 실험과 직접 API·외부 CLI·픽셀/ML/콘텐츠 주소 대안을 비교했다. 메인 테스트28개 중27통과·Windows symlink 권한1skip, 하드링크와 별도 junction은 실제 검증했다. 독립 identity probe13항목과 메인 대조15항목도 통과했다.

최종 코드를 별도 프로젝트·새 venv로 복제한 독립 재현도28개 중27통과·1skip, 동일 CLI 결과·원본10개 보존을 확인했다. 관련 코드 SHA와 audit는 [HANDOFF](HANDOFF.md)에 연결한다.

PNG getexif/verify 순서, TIFF 파서 자동회전·load후 태그 변경, JPEG verify/load 차이, Windows DirEntry 파일ID=0, 오류 객체 주소의 비결정성, 수정일과 companion 태그의 IFD 분리를 실제 실패·코드수정·테스트로 남겼다. 원본/기존 제품의 내용 해시는 보존됐다. [인계 자료](HANDOFF.md)와 각 R에서 재현 코드·데이터·로그로 이어진다.

HEIC/RAW/실물 카메라·XMP/sidecar·유사 사진 정확도·대량 성능·최종 UX는 미검증 또는 이후 선택으로 유지한다. 기본 제한은 에이전트가 만든 작은 연구 작업장용 정책이며 제품 제약으로 고정하지 않는다. 결과 기준 변경이나 추가 제품 선택은 없었다.

## 세션 종료

사용자가 전달한 연구 결과와 남은 한계를 확인하고 현재 재료·결론으로 종료하도록 명시했다. 이에 따라 세션을 완료한다. 미확인 기능을 성공으로 변경하거나 제품 선택을 추가 확정하지 않았다. 종료 처리에서는 상태·최종 기록·자료 해시 목록만 갱신했고 코드/원본을 변경하거나 테스트를 다시 실행하지 않았다.

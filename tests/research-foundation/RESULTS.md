# beta.2 결과와 배포 판단

## 최종 범위

사용자는 진행 중이던 **두 분야 각 2회 실제 평가 및 독립 검토의 잔여 수행을 중단**하고, 식별된 문제를 정리한 뒤 Draft PR·`v1.1.0-beta.2` prerelease·백업/설치까지 마무리하도록 지시했다. [범위 변경 기록](scope-change.json)에 이를 보존한다. 남은 평가를 완료로 계산하지 않는다.

최초 실제 평가 소스는 `7f60615183899d6fdfa47c8391688df600010b02`다. 최종 배포에는 재현 자료 선택·검사 보완과 Lab의 전달/환경값 비교 안내가 추가됐다. 이 최종 변경으로 네 실제 평가를 다시 실행한 것은 아니다.

따라서 **네 번의 시도, 세 번의 후속 조건 반영·세션 종료, 두 번의 외부 재현**을 기록했다. 네 번 모두 독립 검증을 통과했다는 주장은 하지 않는다.

수행자들은 Topology와 R 문서를 만들고 서로 다른 질문의 탐색자·실제 코드·데이터·테스트를 사용했다. 직접 provider·대체 방식·실패 경험, metadata parser·정확 동일성·인접 제품 사례를 비교했다. 일부 생성은 실제 thread limit 때문에 실패했다가 순차 수행됐다. 전체 host trace가 없어 actor 활동 기록, 반환된 자료와 operator가 관측한 agent tree·공개 응답·파일을 구분한다.

사실 설명과 실제 실행, 실제 실패와 주입한 실패, 재분석과 관측, 동일 바이트와 시각적 유사성을 구분한 점을 관찰했다. 이를 다른 모델·effort, 더 큰 실제 데이터나 모든 연구의 품질 우위로 일반화하지 않는다.

## 발견한 문제와 수정

1. **재현 프롬프트 드리프트:** 최초 평가 전에 prepare→export→reproduce의 고정 사본·해시를 연결했다. 현재 안내 파일로 자동 대체하지 않는다.
2. **이전 실행 기록의 혼입:** 첫 raw reproduction 준비가 Lab 내부 활동/재실행 기록까지 복사했다. 그 작업장은 재현 모델에 제공하지 않았다. [선택 방식](reproduction-selection.md)으로 코드·데이터·테스트·설명만 전달했고, 현재 기본 명령도 이 방식을 사용한다. `clean-reproduction` 같은 경로와 ZIP 안의 해당 기록도 확인한다.
3. **사진 검증의 환경 의존성:** [원래 실패](results/photos-sample1/repair-01/before-results.json)를 보존하고, [별도 수정본](results/photos-sample1/repair-01/export-01/artifacts/project/.elenchus/HANDOFF.md)을 만들었다. 실제 수정 시각과 원본 보존 검사는 유지하며 portable 결과 비교만 분리했다. 같은 길이의 파일 내용 변경·날짜 의미 변경·필드 누락은 계속 실패한다. [수정 기록](results/photos-sample1/repair-01/repair.json)과 [차이](results/photos-sample1/repair-01/change.patch)를 남겼다.
4. **패키지 검사의 작업장 혼입:** 기존 패키지 검사가 저장소 전체를 복사해 무시된 실제 평가 venv/cache까지 가져갈 수 있었다. 검사 대상으로 현재 runtime payload와 LICENSE/README를 준비하도록 변경했다. 과거 모델 실행 기록은 수정하지 않았다.

사진 수정본은 operator 검증에서 **31개 중 30 통과·symlink 1 skip, 로컬 검증 13/13**이었다. 핵심 스캐너·렌더러와 원본 입력 bytes를 보존했다. 추가 독립 재현은 사용자 요청으로 취소됐으며 operator 수정을 최초 수행 모델의 깨끗한 성공으로 바꾸지 않는다.

Lab 지침에도 실제 전달 묶음을 새 위치에서 재현하고, 기능/내용의 불변 조건과 환경별 진단값을 구분하도록 반영했다. 이 안내는 파일 시각 자체가 연구 입력인 경우 그 의미를 무시하라는 규칙이 아니다.

## 기록·한계와 배포

실제 actor 입력·고정 답변·공개 응답·활동 기록·수집본을 보존했다. 네 export는 각각 123·205·119·212개의 검토한 파일을 복사했으며 그 범위의 해시와 최초 입력/runtime/제품 파일 불변을 확인했다. 가상환경·캐시·일부 외부 문서 원문은 공개 대상에서 제외하고 이유를 남겼다. 재현용 선택에서는 과거 활동/재실행 기록을 추가로 제외했으며, HANDOFF와 R에 적힌 제작자의 결과 설명은 재료의 맥락으로 남는다.

모델 지정은 네 actor 모두 `gpt-6-astra`/`xhigh`, 새 맥락이었다. 이는 관측한 생성 인자이며 모델 내부 telemetry는 노출되지 않았다. native의 완전한 도구 trace·토큰·순수 처리 시간은 제공되지 않아 추정하지 않는다. CLI 검사는 실제 subprocess 시간·반환된 사용량과 공개 이벤트를 별도로 기록한다.

[최초 소스 해시](baseline/primary/freeze.json)와 `runtime.zip`은 당시 제공한 Git blob bytes다. 현재 도구는 평가 후 수정됐으므로 당시 방법을 복원할 때는 기록한 커밋의 도구를 사용한다. 완료되지 않은 재현을 보충하기 위한 새 실행은 이번 작업에서 하지 않는다.

이번 배포는 실사용을 위한 **prerelease**다. Draft PR로 제안하며 main과 beta.1 릴리스를 보존한다. 현재 스킬에 영구적으로 중단 규칙을 추가한 것은 아니며, 사용자 요청에 따라 이번 개발 평가의 남은 범위만 종료했다.

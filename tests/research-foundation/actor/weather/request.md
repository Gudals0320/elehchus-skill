$elenchus

공개 기상 데이터를 받아 로컬에서 분석할 때 쓸 수 있는 기능적 재료를 준비하고 싶어.

현재 환경에서 실제로 데이터를 가져오고, 시간·단위·누락 값을 다룰 수 있게 정리해서 SQLite에 넣고 다시 조회하는 경로를 만들어보고 싶어. 제공 방식을 조사하고 라이브러리나 데이터 처리 방법도 비교하면서, 실제 실행할 때 생기는 제약과 시행착오를 미리 겪어보자.

이후 개발자가 이어 쓸 수 있는 코드, 실제 응답의 필요한 샘플, 테스트와 실행 방법을 남겨줘. 전체 제품의 화면이나 종합 사용자 경험은 여기서 정하지 않을 거야. 웹 조회와 독립적인 subagent 조사·실험, 독립 연구 작업장에서의 구현과 실행을 사용해도 돼. 계정 생성·개인정보·비밀키·유료 서비스는 쓰지 말자.
